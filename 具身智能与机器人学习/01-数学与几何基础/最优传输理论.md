## 1. 为什么最优传输对生成模型至关重要

### 1.1 核心问题：如何把噪声变成数据

所有生成模型的核心任务本质上是**分布变换**：从一个简单分布（如标准高斯 $\mathcal{N}(0, I)$）变换到复杂的数据分布 $p_{\text{data}}$。

$$
\mathbf{z} \sim \mathcal{N}(0, I) \quad \longrightarrow \quad \mathbf{x} \sim p_{\text{data}}
$$

这个变换的质量决定了生成模型的效率：如果映射路径弯曲、冗余，就需要很多步去逼近；如果路径是直的，理论上一步就够了。

### 1.2 三种分布变换哲学

| 方法 | 路径特征 | 代表模型 |
|------|---------|----------|
| **VAE** | 单次随机映射，高斯瓶颈 | VAE, VQ-VAE |
| **Diffusion** | 随机弯曲路径（SDE），逐步去噪 | DDPM, Score-SDE |
| **Flow Matching / OT** | 确定性直线插值（ODE），最少步数 | Flow Matching, Rectified Flow |

> **最优传输理论回答的问题是：在所有可能的分布变换中，哪一条是"最短"的？答案是直线。**

### 1.3 直观类比：搬土问题

想象你有两堆土：一堆堆在位置 $\{\mathbf{x}_i\}$，另一堆堆在位置 $\{\mathbf{y}_j\}$。你想把第一堆土搬运成第二堆的样子。**最优传输就是最小化总搬运功的搬运方案。**

把"土堆"替换成"概率分布"，这就是最优传输理论在生成模型中的角色：
- 源分布 $\mu$ = 噪声分布（如高斯）
- 目标分布 $\nu$ = 数据分布（如图像）
- 传输代价 = 移动概率质量的距离

## 2. Monge 问题：确定性的传输映射

### 2.1 数学表述

Monge (1781) 提出了最优传输问题的原始形式：

给定两个概率测度 $\mu$（源分布）和 $\nu$（目标分布），找一个映射 $T: \mathbb{R}^d \to \mathbb{R}^d$ 满足：

$$
\boxed{\min_{T} \int_{\mathbb{R}^d} c(\mathbf{x}, T(\mathbf{x})) \, d\mu(\mathbf{x}) \quad \text{s.t.} \quad T_{\#}\mu = \nu}
$$

参数说明：
- $\mu$：源概率测度（噪声分布），定义在 $\mathbb{R}^d$ 上
- $\nu$：目标概率测度（数据分布），定义在 $\mathbb{R}^d$ 上
- $T: \mathbb{R}^d \to \mathbb{R}^d$：传输映射，将源空间的点映射到目标空间
- $c(\mathbf{x}, \mathbf{y})$：代价函数，通常取欧氏距离平方 $c(\mathbf{x}, \mathbf{y}) = \|\mathbf{x} - \mathbf{y}\|^2$
- $T_{\#}\mu = \nu$：push-forward 约束——对于任意可测集 $B$，$\mu(T^{-1}(B)) = \nu(B)$，即映射后 $\mu$ 的质量分布恰好等于 $\nu$

### 2.2 Monge 问题的三大局限性

| 局限性 | 具体表现 | 为什么对生成模型是个问题 |
|--------|---------|-------------------------|
| **映射可能不存在** | 当 $\mu$ 是 Dirac 分布而 $\nu$ 不是时，不存在这样的 $T$ | 噪声分布是连续的，但数据分布可能有离散结构（如类别） |
| **映射不唯一** | 有多个 $T$ 满足 push-forward 约束 | 无法确定哪一个是"最优"的传输路径 |
| **不可叠加** | 将两堆土分给两个地点时，Monge 不允许**分裂**一个点的质量 | 生成模型中，"同一类噪声"可能需要对应"多种数据模式" |

> **核心矛盾：Monge 要求"一个萝卜一个坑"（确定性双射），但真实数据的分布变换需要"一个萝卜可能对应多个坑的混合"。**

## 3. Kantorovich 松弛：概率耦合视角

### 3.1 核心思想：用联合分布代替确定性映射

Kantorovich (1942) 的突破性松弛：**允许概率质量分裂和混合。**

不找映射 $T$，而是找一个联合分布（coupling）$\gamma(\mathbf{x}, \mathbf{y})$：

$$
\boxed{\min_{\gamma \in \Pi(\mu, \nu)} \int_{\mathbb{R}^d \times \mathbb{R}^d} c(\mathbf{x}, \mathbf{y}) \, d\gamma(\mathbf{x}, \mathbf{y})}
$$

其中 $\Pi(\mu, \nu)$ 是所有边缘分布分别为 $\mu$ 和 $\nu$ 的联合分布的集合：

$$
\Pi(\mu, \nu) = \left\{ \gamma : \int \gamma(\mathbf{x}, \mathbf{y}) \, d\mathbf{y} = \mu(\mathbf{x}), \;\; \int \gamma(\mathbf{x}, \mathbf{y}) \, d\mathbf{x} = \nu(\mathbf{y}) \right\}
$$

参数说明：
- $\gamma(\mathbf{x}, \mathbf{y})$：耦合（coupling）——描述源点 $\mathbf{x}$ 和目标点 $\mathbf{y}$ 之间的概率质量流动
- $\Pi(\mu, \nu)$：传输计划的集合——所有满足边缘约束的联合分布
- 边缘约束保证：从 $\mathbf{x}$ 流出的总质量 = $\mu(\mathbf{x})$，流入 $\mathbf{y}$ 的总质量 = $\nu(\mathbf{y})$

### 3.2 直观理解：从"硬指派"到"软分配"

$$
\begin{aligned}
\text{Monge（1781）} &: \mathbf{y} = T(\mathbf{x}) \quad \text{——确定性：} \mathbf{x} \text{ 只能去一个 } \mathbf{y} \\[6pt]
\text{Kantorovich（1942）} &: \gamma(\mathbf{x}, \mathbf{y}) \quad\; \text{——概率化：} \mathbf{x} \text{ 可以按比例分给多个 } \mathbf{y}
\end{aligned}
$$

**对于生成模型：** Kantorovich 松弛允许噪声点 $\mathbf{z}$ 以某种概率映射到不同的数据点，这恰好是生成多样性所需要的——两个相似的噪声输入应该可以生成两个不同的合理图像。

### 3.3 对偶形式

Kantorovich 问题有精确的对偶形式（Kantorovich duality）：

$$
\boxed{\max_{\varphi, \psi} \int \varphi(\mathbf{x}) \, d\mu(\mathbf{x}) + \int \psi(\mathbf{y}) \, d\nu(\mathbf{y}) \quad \text{s.t.} \quad \varphi(\mathbf{x}) + \psi(\mathbf{y}) \leq c(\mathbf{x}, \mathbf{y})}
$$

当 $c(\mathbf{x}, \mathbf{y}) = \|\mathbf{x} - \mathbf{y}\|^2$ 时，对偶变量满足 $\psi = -\varphi^*$（凸共轭），从而退化为 Brenier 定理的形式。

## 4. Wasserstein 距离：搬土距离

### 4.1 定义

$p$-Wasserstein 距离定义为 Kantorovich 问题在代价 $c(\mathbf{x}, \mathbf{y}) = \|\mathbf{x} - \mathbf{y}\|^p$ 下的最优值：

$$
\boxed{W_p(\mu, \nu) = \left( \inf_{\gamma \in \Pi(\mu, \nu)} \int \|\mathbf{x} - \mathbf{y}\|^p \, d\gamma(\mathbf{x}, \mathbf{y}) \right)^{1/p}}
$$

最常用的是 $p=2$ 的情形：

$$
\boxed{W_2^2(\mu, \nu) = \inf_{\gamma \in \Pi(\mu, \nu)} \int \|\mathbf{x} - \mathbf{y}\|^2 \, d\gamma(\mathbf{x}, \mathbf{y})}
$$

### 4.2 为什么 Wasserstein 距离优于 KL 散度

| 性质 | KL散度 $D_{\text{KL}}(P\|Q)$ | Wasserstein距离 $W(P, Q)$ |
|------|------------------------------|---------------------------|
| **对称性** | 不对称 | ✅ 对称 |
| **三角不等式** | 不满足 | ✅ 满足（是真实的度量） |
| **支撑集不重叠** | 发散 → +∞ | ✅ 仍有有限值 |
| **梯度平滑性** | 可能消失或爆炸 | ✅ 处处有意义的梯度 |

> **关键优势：当两个分布的支撑集不重叠时，Wasserstein 距离仍能提供有意义的梯度信号。** 这正是 WGAN 使用 Wasserstein 距离替代 JS 散度的原因。

### 4.3 两个高斯分布间的 $W_2$（解析解）

对于两个高斯分布 $\mu = \mathcal{N}(\mathbf{m}_1, \Sigma_1)$，$\nu = \mathcal{N}(\mathbf{m}_2, \Sigma_2)$：

$$
\boxed{W_2^2(\mu, \nu) = \|\mathbf{m}_1 - \mathbf{m}_2\|^2 + \operatorname{tr}\left( \Sigma_1 + \Sigma_2 - 2(\Sigma_1^{1/2} \Sigma_2 \Sigma_1^{1/2})^{1/2} \right)}
$$

当协方差矩阵可交换时（如对角矩阵），简化为：

$$
W_2^2 = \|\mathbf{m}_1 - \mathbf{m}_2\|^2 + \|\Sigma_1^{1/2} - \Sigma_2^{1/2}\|_F^2
$$

## 5. OT Map 作为直线插值

### 5.1 Brenier 定理：最优映射是梯度的梯度的梯度

当 $c(\mathbf{x}, \mathbf{y}) = \|\mathbf{x} - \mathbf{y}\|^2$ 且 $\mu$ 是绝对连续的（有密度），存在一个凸函数 $\varphi$ 使得最优传输映射为：

$$
\boxed{T(\mathbf{x}) = \nabla \varphi(\mathbf{x})}
$$

即：**最优传输映射是某个凸函数的梯度。**

参数说明：
- $\varphi: \mathbb{R}^d \to \mathbb{R}$：Brenier 势函数，必须是凸函数
- $\nabla \varphi$：$\varphi$ 的梯度，由凸性保证是单调映射
- 这个结果来自凸分析中的 Brenier-McCann 定理

### 5.2 McCann 插值：直线上插值

给定最优传输映射 $T$，McCann 插值定义了从 $\mu$ 到 $\nu$ 的**直线路径**：

$$
\boxed{\mu_t = \left( (1-t)\mathbf{id} + t T \right)_{\#} \mu, \quad t \in [0, 1]}
$$

其中 $\mathbf{id}(\mathbf{x}) = \mathbf{x}$ 是恒等映射。沿此插值的速度场是：

$$
\boxed{\mathbf{v}_t(\mathbf{x}) = T(\mathbf{x}) - \mathbf{x}}
$$

参数说明：
- $t \in [0,1]$：时间参数，$t=0$ 为源分布 $\mu$，$t=1$ 为目标分布 $\nu$
- $\mathbf{id}$：恒等映射，保持点不变
- $\mathbf{v}_t(\mathbf{x})$：速度场（vector field），指示概率质量流动的方向和速率
- $((1-t)\mathbf{id} + tT)_{\#}\mu$：push-forward，将 $\mu$ 沿直线从 $\mathbf{x}$ 推向 $T(\mathbf{x})$

### 5.3 这意味着什么

> **沿最优传输路径的运动是匀速直线的。** 每个粒子从 $\mathbf{x}$ 沿直线移动到 $T(\mathbf{x})$，速度为常数 $T(\mathbf{x}) - \mathbf{x}$。

这就是 Flow Matching 能使用更少步骤的**根本数学原因**：
- 如果目标是直线，预测直线的方向远比预测弯曲路径简单
- 直线路径可以用大步长的 ODE 求解器（如 Euler）一步或几步完成
- 不需要像 Diffusion 那样用小步长模拟弯曲的 SDE

## 6. 连接 Flow Matching：OT 提供直线，FM 来学习

### 6.1 Flow Matching 的数学框架

Flow Matching 的目标是学习一个**向量场** $\mathbf{v}_\theta(\mathbf{x}, t)$，使得从 $t=0$ 到 $t=1$ 沿 ODE 流动能将噪声分布变换为数据分布：

$$
\frac{d\mathbf{x}}{dt} = \mathbf{v}_\theta(\mathbf{x}, t), \quad \mathbf{x}(0) \sim \mu, \quad \mathbf{x}(1) \sim \nu
$$

### 6.2 条件流匹配：用 OT 对构造训练信号

条件 Flow Matching (Lipman et al., 2023) 的核心技巧：

1. 从数据中抽取 $\mathbf{x}_1 \sim \nu$（真实数据）
2. 从噪声中抽取 $\mathbf{x}_0 \sim \mu$（噪声）
3. **假设直线插值路径**（OT 的启发）：

   $$
   \boxed{\mathbf{x}_t = (1-t)\mathbf{x}_0 + t\mathbf{x}_1}
   $$

4. 因此真实速度场为（直线方向）：

   $$
   \boxed{\mathbf{v}(\mathbf{x}_t, t) = \mathbf{x}_1 - \mathbf{x}_0}
   $$

5. 训练目标：让网络预测的速度场匹配真实速度场

   $$
   \boxed{\mathcal{L}_{\text{CFM}} = \mathbb{E}_{t, \mathbf{x}_0 \sim \mu, \mathbf{x}_1 \sim \nu} \left[ \|\mathbf{v}_\theta(\mathbf{x}_t, t) - (\mathbf{x}_1 - \mathbf{x}_0)\|^2 \right]}
   $$

参数说明：
- $\mathbf{x}_0 \sim \mu$：从噪声分布采样的起点
- $\mathbf{x}_1 \sim \nu$：从数据分布采样的终点
- $\mathbf{x}_t = (1-t)\mathbf{x}_0 + t\mathbf{x}_1$：直线插值的中间点
- $\mathbf{v}_\theta(\mathbf{x}_t, t)$：神经网络预测在 $(\mathbf{x}_t, t)$ 处的速度方向
- $(\mathbf{x}_1 - \mathbf{x}_0)$：真实目标——从 $\mathbf{x}_0$ 指向 $\mathbf{x}_1$ 的直线方向
- $t \sim \mathcal{U}(0, 1)$：均匀采样的时间步

### 6.3 Jensen 间隙与路径曲率

**为什么 OT 启发式路径比 Diffusion 路径更高效？**

Flow Matching 的损失（条件速度匹配）与连续归一化流的真实损失之间存在 Jensen 间隙（Jensen gap）。间隙的大小取决于路径的**曲率**：

- OT 直线路径：曲率 = 0，Jensen 间隙最小 → 学习高效
- Diffusion SDE 路径：曲率 > 0，Jensen 间隙较大 → 需要更多训练
- VAE 单步路径：无路径概念，但容量损耗大 → 质量受限

## 7. Rectified Flow：迭代拉直

### 7.1 核心思想

Rectified Flow 是一种**自举式训练策略**，通过反复在模型自身的生成路径上重新训练，使路径逐步变直：

$$
\begin{aligned}
\text{第 } k \text{ 轮：} \quad &\mathbf{x}_{t}^{(k)} \sim \text{Flow}_\theta^{(k)} \quad (\text{用上一轮模型生成样本}) \\
&\text{训练 } \mathbf{v}_\theta^{(k+1)} \text{ 去匹配 } \mathbf{x}_{t}^{(k)} \text{ 的速度场}
\end{aligned}
$$

### 7.2 直观理解：反复"绷直"绳子

```
初始 (随机配对):  ～～～～～～ (弯曲)
第 1 轮 Rectify:  ~~~~ (部分拉直)
第 2 轮 Rectify:  ~~~ (更直)
第 3 轮 Rectify:  --- (几乎直线)
```

**定理（Rectified Flow）：** 经过 $k$ 轮整流后，路径曲率以指数速度递减：
- 1 轮：直线路径（条件最优传输）
- 2 轮：进一步减少交叉路径（自一致性）
- 3 轮+：路径几乎完全拉直 → **2步采样即可**

### 7.3 与 Distillation 的对比

| 方法 | 思路 | 路径质量 |
|------|------|---------|
| **Rectified Flow** | 在自己的轨迹上重新训练 | 多轮迭代后，模型学习到的路径本身越来越直 |
| **Distillation（蒸馏）** | 用教师模型的大步长输出来训练学生 | 一步到位，但依赖教师质量 |
| **Flow Matching（单轮）** | 用随机配对训练一次 | 仅保证条件最优（每个 (noise, data) pair 是直线） |

> Rectified Flow 的关键洞察：单轮 Flow Matching 只在**条件分布**层面是直线（给定 $(\mathbf{x}_0, \mathbf{x}_1)$ 的特定配对），但**边缘分布**的路径仍可能交叉。迭代拉直消除了这种交叉。

## 8. 对比：OT 路径 vs Diffusion SDE 路径 vs VAE 路径

### 8.1 路径几何对比

| 维度 | OT / Flow Matching | Diffusion (SDE) | VAE |
|------|-------------------|-----------------|-----|
| **路径类型** | 确定性直线 (ODE) | 随机弯曲 (SDE) | 单步随机 (无路径) |
| **路径方程** | $\dot{\mathbf{x}} = \mathbf{v}(\mathbf{x}, t)$ | $d\mathbf{x} = \mathbf{f}dt + g d\mathbf{w}$ | $\mathbf{x} = \text{Dec}(\mathbf{z}),\; \mathbf{z} \sim q(\mathbf{z}|\mathbf{x})$ |
| **步数需求** | 2~10 步（直线可大步长） | 50~1000 步（需小步模拟SDE） | 1 步（但质量受限） |
| **采样速度** | 🔥🔥🔥 极快 | 🔥 慢 | 🔥🔥🔥🔥 最快 |
| **生成质量** | 🔥🔥🔥 高 | 🔥🔥🔥🔥 最高 | 🔥🔥 中等 |
| **曲率** | 0（直线） | > 0（弯曲） | 不适用（一步） |
| **随机性** | 确定性的（ODE） | 随机性的（SDE） | 随机性的（采样） |
| **速度场形式** | $\mathbf{v}(\mathbf{x}, t)$ | score $\nabla \log p_t(\mathbf{x})$ | encoder/decoder |

### 8.2 路径可视化示意

```
OT (Flow Matching):           Diffusion (SDE):              VAE:
                                                              
  noise ●──────────→ data       noise ●～～～～～→ data       noise ●─→ z ─→ data
          直线，最快                  随机弯曲                      单步，有瓶颈
```

### 8.3 为什么直线路径能用更少步数

**Diffusion 需要小步长的原因：**
- SDE 的漂移项和扩散项在每个时间步都注入随机性
- 路径弯曲，大步长会偏离真实路径
- 需要用数值 SDE 求解器（如 Euler-Maruyama），步长由 $\sqrt{\Delta t}$ 的扩散项决定

**Flow Matching 可以用大步长的原因：**
- ODE 是确定性的，没有扩散项
- 路径是直线，预测 $\mathbf{x}_1 - \mathbf{x}_0$ 方向在每一步都是对的
- 即使 ODE 求解器有误差，也不会累积随机噪声
- 实际上：Flow Matching + Heun 求解器，5~10 步即可达到扩散 100 步的质量

### 8.4 数学对比：ODE vs SDE

$$
\begin{aligned}
\text{Flow Matching (ODE)} &: \quad \frac{d\mathbf{x}}{dt} = \mathbf{v}_\theta(\mathbf{x}, t) \quad \text{——确定性，可逆} \\[6pt]
\text{Diffusion (SDE)} &: \quad d\mathbf{x} = \underbrace{\mathbf{f}(\mathbf{x}, t)dt}_{\text{漂移}} + \underbrace{g(t)d\mathbf{w}}_{\text{扩散}} \quad \text{——随机，路径不唯一}
\end{aligned}
$$

两者的概率流 ODE（PF-ODE）等价于 score-based 模型的 Fokker-Planck 方程均值，但 Flow Matching 直接学习该 ODE 的速度场，跳过了 score estimation 的中间步骤。

## 9. Python 伪代码：Sinkhorn 算法计算 Wasserstein 距离

### 9.1 Sinkhorn 算法原理

对于离散分布，Kantorovich 问题变为线性规划。Sinkhorn 算法通过熵正则化将其变为可快速迭代求解的问题：

$$
\boxed{\min_{\gamma} \sum_{i,j} \gamma_{ij} \, c_{ij} - \varepsilon \, H(\gamma) \quad \text{s.t.} \quad \gamma \mathbf{1} = \mathbf{a}, \; \gamma^T \mathbf{1} = \mathbf{b}}
$$

其中 $H(\gamma) = -\sum_{i,j} \gamma_{ij}(\log \gamma_{ij} - 1)$ 是熵正则项，$\varepsilon > 0$ 是正则化强度。

### 9.2 2D Wasserstein 距离计算代码

```python
"""
Sinkhorn 算法：计算两个离散 2D 分布之间的熵正则化 Wasserstein 距离
用途：理解 OT 的计算原理，验证直线路径假设
"""
import numpy as np


def sinkhorn_wasserstein(
    a: np.ndarray,       # 源分布权重, shape (n,), sum(a) = 1
    b: np.ndarray,       # 目标分布权重, shape (m,), sum(b) = 1
    X: np.ndarray,       # 源点坐标, shape (n, 2)
    Y: np.ndarray,       # 目标点坐标, shape (m, 2)
    eps: float = 0.01,   # 熵正则化强度 (越小 → 越接近精确 OT, 但收敛越慢)
    max_iter: int = 100, # 最大迭代次数
    tol: float = 1e-9,   # 收敛阈值
) -> tuple[float, np.ndarray]:
    """
    返回:
        W: 近似的 Wasserstein 距离
        P: 传输计划矩阵, shape (n, m), P[i,j] = 从 i 到 j 的质量流
    """
    n, m = len(a), len(b)

    # Step 1: 构建代价矩阵 (欧氏距离平方)
    # C[i,j] = ||X[i] - Y[j]||^2
    C = np.sum((X[:, None, :] - Y[None, :, :]) ** 2, axis=-1)
    # 形状: (n, m)

    # Step 2: 构建 Gibbs 核 K = exp(-C / eps)
    K = np.exp(-C / eps)  # shape: (n, m)

    # Step 3: Sinkhorn 迭代求解缩放因子
    # 寻找向量 u, v 使得 diag(u) @ K @ diag(v) 的行和为 a, 列和为 b
    u = np.ones(n)        # 行缩放因子
    v = np.ones(m)        # 列缩放因子

    for it in range(max_iter):
        u_old = u.copy()

        # 交替更新: 固定 v 更新 u, 固定 u 更新 v
        # u = a / (K @ v)     — 确保行和 = a
        # v = b / (K^T @ u)   — 确保列和 = b
        u = a / (K @ v + 1e-16)
        v = b / (K.T @ u + 1e-16)

        # 检查收敛
        if np.max(np.abs(u - u_old)) < tol:
            break

    # Step 4: 重建传输计划
    P = np.diag(u) @ K @ np.diag(v)  # shape: (n, m), 近似满足边缘约束

    # Step 5: 计算 Wasserstein 距离
    W = np.sqrt(np.sum(P * C))

    return W, P
```

### 9.3 参数调优指南

| eps 值 | 收敛速度 | 精度 | 适用场景 |

## 10. 总结：OT 在生成模型中的角色

### 10.1 核心逻辑链

```
最优传输 → 直线路径 → 条件流匹配 → 少步采样 → 快速生成
    ↓            ↓           ↓            ↓           ↓
 Wasserstein   McCann    CFM Loss    ODE求解器    实用部署
  距离度量    插值定理    (速度匹配)  (大步长)    (实时生成)
```

### 10.2 一句话总结

> **最优传输理论证明了：噪声到数据的最短路径是直线。Flow Matching 学会沿这条直线走，因此只需要几步就能到达终点。**
