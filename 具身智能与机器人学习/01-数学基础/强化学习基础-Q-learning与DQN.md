# 强化学习基础：Q-learning 与 DQN

> **定位**：人形端到端栈 **L1 RL 地基**。上一篇 [[强化学习基础-贝尔曼方程与动态规划]] 讲了"已知模型怎么解"（动态规划）；本篇解决"**模型未知**时怎么办"——这是机器人场景的常态。教学目标：**手推一次 Q-learning 更新，说清 DQN 三件套为什么必要**。
>
> 前置：[[强化学习基础-贝尔曼方程与动态规划]]（贝尔曼最优方程是本节目标）。下一篇衔接：[[强化学习策略-PPO与SAC]]（策略梯度法）。

## 一、从"已知模型"到"只靠采样"

动态规划的死穴：需要 $\mathcal{P}(s'|s,a)$。机器人环境里：

- 仿真引擎的转移"理论上"可查，但状态连续 → 无法枚举
- 真机根本没有转移函数，只有**一次次的实际经历** $(s, a, r, s')$

**model-free 核心思想**：用**采样平均**代替期望。贝尔曼方程里的 $\sum_{s'}\mathcal{P}(s'|s,a)[\cdot]$ 是期望，而期望 = 大量采样的平均——那就不建模，直接采样。

## 二、时序差分（TD）：边采样边学

### 2.1 蒙特卡洛（MC）vs 时序差分（TD）

| 方法 | 怎么估计 $V(s_t)$ | 特点 |
|------|------------------|------|
| MC | 跑完一整条轨迹，用真实回报 $G_t$ 更新 | 无偏、高方差、要等轨迹结束 |
| **TD(0)** | 走一步就更新：用 $r_{t+1} + \gamma V(s_{t+1})$ 当目标 | **有偏（自举）、低方差、在线可学** |

TD 更新（对值函数）：

$$V(s_t) \leftarrow V(s_t) + \alpha\Big[ \underbrace{r_{t+1} + \gamma V(s_{t+1})}_{\text{TD 目标}} - \underbrace{V(s_t)}_{\text{当前估计}} \Big]$$

括号里是 **TD 误差** $\delta_t$：新信息与旧估计之差。α 是学习率。

**直觉**：走一步，看到"实际奖励 + 对未来的估计"，用这个比旧估计更"新鲜"的目标微调自己。

## 三、Q-learning：off-policy 地逼近 $Q^*$

### 3.1 更新规则（核心，必推）

目标：逼近贝尔曼最优方程里的 $Q^*$。把 TD 更新套到 Q 函数上，并把"未来的估计"换成**贪心的最优值**：

$$Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha\Big[ r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a') - Q(s_t, a_t) \Big]$$

**为什么用 max 而不是按策略加权？**

- 动态规划部分讲过：最优动作 = 使"一步奖励 + 最优未来"最大
- 用 $\max_{a'}$ 就是在**估计 $Q^*$ 本身**，而不是"策略 π 下的 Q"
- 所以 Q-learning 是 **off-policy**：**行为策略**（怎么探索，如 ε-greedy）和**目标策略**（学谁，最优策略）可以不同

### 3.2 ε-greedy 探索

- 以 ε 概率随机探索（避免一直走已知的路），1-ε 概率选当前最优动作
- 训练时 ε 从 1.0 逐渐衰减到 ~0.05（先大胆探索，后精细利用）
- **探索-利用权衡**是 RL 的永恒主题：不走没走过的路就永远不知道更好的路

### 3.3 表格 Q-learning 的收敛条件

表格法（每个 (s,a) 一格）下，只要：① 无限次访问所有 (s,a)；② 学习率满足 Robbins-Monro 条件（$\sum\alpha=\infty, \sum\alpha^2<\infty$），Q 一定收敛到 $Q^*$。**但机器人状态连续 → 表格爆炸 → 必须函数逼近。**

## 四、DQN：用神经网络代替表格

**Deep Q-Network**（Mnih et al., 2015，打爆 Atari 的那篇）：用网络 $Q_\theta(s,a)$ 拟合 Q 函数。

$$\text{损失：} L(\theta) = \mathbb{E}_{(s,a,r,s')\sim\mathcal{D}}\Big[ \big( \underbrace{r + \gamma \max_{a'} Q_{\theta^-}(s',a')}_{\text{目标（用目标网络 } \theta^- \text{ 算）}} - Q_\theta(s,a) \big)^2 \Big]$$

### 三件套（为什么缺一不可）

| 技巧 | 解决的问题 | 机制 |
|------|-----------|------|
| **经验回放（replay buffer）** | 在线样本强相关 → 训练不稳定 | 把经历存进池子，随机抽样打破相关性（也提高数据利用率） |
| **目标网络（target network）** | 目标跟着参数一起变 → 目标在移动，无法收敛 | 用冻结的旧参数 $\theta^-$ 算目标，每 N 步同步一次 |
| **Double DQN** | $\max_{a'}$ 会**过估计**（噪声只会往大偏） | 用当前网络选动作 $a^*=\arg\max_{a'}Q_\theta$，用目标网络给它打分 |

> **为什么过估计是问题**：$\max$ 对噪声敏感——某个动作恰好被高估了一点，max 就会选中它，误差被持续放大。Double DQN 把"选"和"评"分开，拆掉这个放大器。

### 4.1 DQN 的局限（为什么机器人控制不用它）

1. **连续动作空间**：$\max_{a'} Q(s',a')$ 需要对连续动作求最大化——每步都要解一个优化，太慢
2. 确定性策略：DQN 学出的动作是"唯一最优"，而机器人任务往往多解（多模态）
3. 于是：**策略梯度法（Actor-Critic / PPO / SAC）** 直接学"动作分布"，绕开这两个问题

## 五、从值函数法到策略梯度法（衔接 PPO/SAC）

| | 值函数法（Q-learning/DQN） | 策略梯度法（PPO/SAC） |
|---|---|---|
| 学什么 | 先学 Q，动作 = argmax Q | 直接学策略 π(a\|s) 的分布参数 |
| 动作空间 | 离散友好，连续要额外优化 | **天然支持连续动作** |
| 随机性 | 靠 ε 探索 | 策略自带随机（探索 = 分布方差） |
| 机器人里 | 少用（连续控制为主） | **主流**（Isaac Gym/Lab 默认 PPO） |

两者不是对立：**Actor-Critic 同时学策略（Actor）和值函数（Critic）**——PPO 的 Critic 就是价值网络，用 TD/GAE 训练（见 [[强化学习策略-PPO与SAC]] 的 GAE 公式）。

## 六、在人形机器人里的映射

| 概念 | 人形场景 |
|------|---------|
| Q(s,a) | "在当前姿态 s 下做动作 a，长期能得多少分" |
| 经验回放 | 把仿真里摔过的经历存起来反复学（人形数据太贵） |
| ε-greedy | 训练初期让机器人乱动探索动作空间 |
| 连续动作问题 | 人形动作是 20+ 维连续向量 → 必须策略梯度法（PPO） |
| DQN 的价值 | 理解了它，PPO 里的 Critic、GAE、目标网络全都"似曾相识" |
