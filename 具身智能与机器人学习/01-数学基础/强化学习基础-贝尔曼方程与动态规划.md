# 强化学习基础：MDP、贝尔曼方程与动态规划

> **定位**：人形端到端栈的 **L1 RL 地基**。这是整个强化学习的"公理层"——Q-learning（下一篇）、PPO/SAC（06 模块）全部从这里长出来。本篇教学目标：**手推贝尔曼方程，理解"为什么值函数可以自举（bootstrap）"**。
>

## 一、为什么需要 RL？——机器人的"没演示"问题

模仿学习（ACT/DP）需要人类演示，但人形机器人有太多动作**人类演示不了**（后空翻、在冰面上保持平衡、被推一把后站稳）。这时只能靠 **RL：让机器人自己试错，用"奖励"告诉它对不对**。

```
模仿学习：看演示 → 抄作业（学策略 π）
强化学习：自己试 → 奖励信号 → 学出比演示更好的行为
```

## 二、MDP：把"试错"形式化

**马尔可夫决策过程（Markov Decision Process）**五元组：

$$(\mathcal{S},\; \mathcal{A},\; \mathcal{P},\; \mathcal{R},\; \gamma)$$

| 符号 | 含义 | 人形例子 |
|------|------|---------|
| $\mathcal{S}$ | 状态空间 | 关节角 + 角速度 + 质心位置 + IMU 姿态 |
| $\mathcal{A}$ | 动作空间 | 各关节目标位置 / 力矩 |
| $\mathcal{P}(s'\|s,a)$ | 状态转移概率 | 物理引擎前向模拟（或真机） |
| $\mathcal{R}(s,a)$ | 即时奖励 | 离目标姿态近 +，能耗 -，摔倒 - |
| $\gamma$ | 折扣因子 ∈ [0,1) | 通常 0.99 |

**两条假设**（MDP 的本质）：

1. **马尔可夫性**：$s_{t+1}$ 只依赖 $s_t, a_t$（不依赖更早历史）
2. **奖励只取决于当前 (s,a)**（或 s,a,s'）

**轨迹**（一次完整经历）：

$$\tau = (s_0, a_0, r_1, s_1, a_1, r_2, \dots, s_{T-1}, a_{T-1}, r_T)$$

**回报**（从 t 开始的累计折扣奖励）：

$$G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k r_{t+k+1}$$

**为什么折扣 γ < 1**：① 远期的奖励不确定（模型误差累积）；② 数学上保证无穷和收敛；③ 直觉：今天的 100 块比十年后的 100 块值钱。

## 三、值函数：给"状态"和"动作"打分

**策略** $\pi(a|s)$：在状态 s 下选动作 a 的概率分布。

**状态值函数**（在策略 π 下，从 s 出发的期望回报）：

$$V^{\pi}(s) = \mathbb{E}_{\pi}\left[G_t \,\middle|\, s_t = s\right] = \mathbb{E}_{\pi}\left[\sum_{k=0}^{\infty}\gamma^k r_{t+k+1} \,\middle|\, s_t = s\right]$$

**动作值函数**（在 s 下先选 a、之后遵循 π）：

$$Q^{\pi}(s,a) = \mathbb{E}_{\pi}\left[G_t \,\middle|\, s_t = s, a_t = a\right]$$

关系：$V^{\pi}(s) = \sum_a \pi(a|s)\, Q^{\pi}(s,a)$（值 = 动作值的策略加权平均）。

## 四、贝尔曼方程：RL 的"第一原理"（必推）

### 4.1 推导 $V^\pi$ 的贝尔曼方程

把 $G_t$ 拆成"第一步 + 未来"：

$$G_t = r_{t+1} + \gamma\,\underbrace{(r_{t+2} + \gamma r_{t+3} + \cdots)}_{G_{t+1}} = r_{t+1} + \gamma G_{t+1}$$

两边取期望（在 s_t = s 条件下），并展开"选动作 → 转移"两步：

$$
\begin{aligned}
V^{\pi}(s) &= \mathbb{E}_{\pi}\left[ r_{t+1} + \gamma G_{t+1} \,\middle|\, s_t = s \right] \\[4pt]
&= \sum_{a} \pi(a|s) \sum_{s'} \mathcal{P}(s'|s,a) \Big[ \underbrace{\mathcal{R}(s,a)}_{\text{一步奖励}} + \gamma \underbrace{V^{\pi}(s')}_{\text{未来期望（自举）}} \Big]
\end{aligned}
$$

这就是**贝尔曼方程（Bellman Equation）**。

### 4.2 关键点：自举（bootstrap）

等式右边出现了 $V^{\pi}(s')$ —— **用"自己的未来估计"来更新"现在的估计"**。这既是 RL 高效的原因（不需要等到轨迹结束才学），也是"为什么需要大量迭代才能收敛"的原因（估计互相依赖）。

### 4.3 贝尔曼最优方程

定义最优值函数 $V^*(s) = \max_\pi V^\pi(s)$（最优策略 π* 对应的值）。此时"选动作"从"按策略加权"变成"取最大"：

$$V^{*}(s) = \max_{a} \sum_{s'} \mathcal{P}(s'|s,a)\Big[ \mathcal{R}(s,a) + \gamma V^{*}(s') \Big]$$

$$Q^{*}(s,a) = \sum_{s'} \mathcal{P}(s'|s,a)\Big[ \mathcal{R}(s,a) + \gamma \max_{a'} Q^{*}(s',a') \Big]$$

**核心思想**：最优动作 = 使"一步奖励 + 最优未来"最大——这就是所有 RL 算法的北极星。

## 五、动态规划：已知模型时怎么解（教学例子）

如果 $\mathcal{P}$ 和 $\mathcal{R}$ **已知**（model-based），贝尔曼方程可以直接迭代求解。

### 5.1 策略评估（Policy Evaluation）

给定固定策略 π，反复应用贝尔曼方程直到收敛：

$$V_{k+1}(s) \leftarrow \sum_{a} \pi(a|s) \sum_{s'} \mathcal{P}(s'|s,a)\Big[ \mathcal{R}(s,a) + \gamma V_k(s') \Big]$$

**直觉**：把"未来估计"当作已知，每次迭代都在修正当前估计 → 最终收敛到真实 $V^\pi$。

### 5.2 策略改进（Policy Improvement）

有了 $V^\pi$，对每个状态贪心地选"一步奖励 + 未来最优"最大的动作：

$$\pi'(s) \leftarrow \arg\max_{a} \sum_{s'} \mathcal{P}(s'|s,a)\Big[ \mathcal{R}(s,a) + \gamma V^{\pi}(s') \Big]$$

**策略改进定理**：$\pi'$ 一定不差于 $\pi$（贪心改进单调不降）。

### 5.3 两种迭代算法

| 算法 | 流程 | 特点 |
|------|------|------|
| **策略迭代** | 评估 → 改进 → 评估 → … 直到策略不变 | 收敛快，每轮评估要迭代多次 |
| **值迭代** | 每步直接做"评估+贪心"合一的更新（用 max 替代加权） | 实现简单，收敛慢一点 |

**小例子（网格世界）**：4×4 网格，目标格奖励 +1，撞墙原地不动，γ=0.9。
- 初值 $V_0$ 全 0 → 迭代一次：目标格邻域得值 1 → 迭代两次：两格之外得 0.9 → 每轮"奖励向外扩散一格并打 γ 折"
- 这个"扩散"过程就是值迭代的直观画面；收敛后每个格子上的值 = "从这里出发的最优期望回报"

### 5.4 动态规划的局限 → 引出下一篇

**DP 需要知道 $\mathcal{P}$ 和 $\mathcal{R}$**。但机器人环境的转移概率（物理引擎）要么太复杂写不出来，要么真机根本无法枚举——所以需要 **model-free** 方法：**不建模，靠采样**。这就是下一篇 Q-learning 的出发点。

## 六、在人形机器人里的映射

| RL 概念 | 人形场景 |
|---------|---------|
| 状态 s | 关节角/速度/姿态（由 L3 状态估计提供） |
| 动作 a | 关节目标位置（Isaac 里常见）或力矩 |
| 奖励 r | "往前走得快 + 姿态稳定 - 摔倒 - 能耗 -" |
| 转移 P | 物理引擎前向积分（仿真）或真机 |
| 为什么 γ=0.99 | 让机器人学会"为了远处的大奖励（走完 10m）忍受眼前的麻烦" |
| 动态规划的局限 | 人形状态连续、转移未知 → 必须 model-free（Q-learning/PPO） |
