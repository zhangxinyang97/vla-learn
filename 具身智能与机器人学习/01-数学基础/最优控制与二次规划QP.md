# 最优控制与二次规划（QP）

> **为什么需要？** 09 模块的 WBC/MPC 全身控制、移动操作的双层轨迹优化，本质都是"解一个最优化问题"。这篇补上最优控制与 QP 的数学骨架，让你读 [[人形机器人全身控制-WBC与MPC]] 时看得懂公式。

## 一、最优控制问题的一般形式

给定离散动力学 $x_{t+1} = f(x_t, u_t)$，找控制序列使总代价最小：

$$\min_{u_0,\dots,u_{T-1}} \; J = \sum_{t=0}^{T-1} c(x_t, u_t) + c_T(x_T)$$

- $x_t$：状态（关节角、速度、质心位置…）
- $u_t$：控制（关节力矩、加速度指令…）
- $c(x,u)$：代价（跟踪误差、能量、平滑性…）
- 约束：动力学方程、关节限位、力矩限幅、防碰撞

**与 RL 的关系**：RL 学的是"策略 π"，最优控制解的是"动作序列"——前者近似后者；最优控制给了可行域/代价的**结构化先验**，这正是分层架构（VLA 高层 + 最优控制低层）的数学依据。

## 二、LQR：最优控制的"hello world"

线性动力学 $x_{t+1} = Ax_t + Bu_t$ + 二次代价 $c = x^TQx + u^TRu$ 时，最优控制是**状态线性反馈**：

$$u_t = -K_t x_t, \qquad K_t \text{ 由 Riccati 递推方程解出}$$

要点：解析可解、计算极快、稳定性有理论保证。所有现代控制器的"内核"都从它出发。

## 三、MPC：滚动时域 + 反复求解

**模型预测控制（Model Predictive Control）**：

1. 在每步用当前状态做初值，求解未来 $T$ 步的最优控制（一次 QP/非线性优化）
2. 只执行第一步 $u_t$
3. 下一时刻用新观测**重新求解**（receding horizon）

- 优点：显式处理约束 + 在线反馈，鲁棒
- 代价：每步都要解一个优化问题 → **实时性依赖求解器速度**
- 在人形机器人上：MPC 常跑在 ~100Hz–1kHz，生成足部落点/重心轨迹

## 四、非线性扩展：iLQR / DDP（直觉）

动力学非线性时，把问题在参考轨迹附近做二阶 Taylor 展开 → 局部 LQR → 迭代求解。iLQR/DDP 是腿足机器人与灵巧手 RL 之外的主流替代。理解"线性化 + 迭代"即可，细节按需再挖。

## 五、二次规划（QP）：WBC 的求解引擎

**标准形式**：

$$\min_{x} \; \frac{1}{2} x^T Q x + q^T x \qquad \text{s.t.} \quad A_{eq}x = b_{eq},\; A_{ineq}x \leq b_{ineq}$$

- $Q \succeq 0$（半正定）时是**凸问题** → 全局最优、求解器成熟（OSQP / qpOASES / PiQP，毫秒级）
- 凸性 = 可预测、可实时——这是机器人任务都"硬凑"成 QP 的原因

### 层级 QP（WBC 的核心结构）

全身控制（Whole-Body Control）把任务按**优先级**排队，逐层求解：

```
Level 1（最高优先）: 质心/平衡约束（站不稳一切白搭）→ 硬约束
Level 2: 脚部/末端任务（落脚点、手的目标位姿）    → 软约束（松弛变量）
Level 3: 关节限位、力矩限幅                      → 硬约束
Level 4: 最小化能量 / 平滑性                     → 目标函数
```

- 每层在满足上一层解的前提下最小化本层代价（null-space projection）
- 松弛变量（slack）让软约束在不可行时"退而求其次"而不是直接失败

### 为什么 WBC 需要 QP 而不是解析公式

关节多（20–40 DOF）、约束多、任务冲突时，解析式解不出来，QP 数值解是唯一出路。

## 六、在具身中的典型用法速查

| 场景 | 优化什么 | 求解器/方法 |
|------|---------|------------|
| 人形站姿/行走 | 质心轨迹 + 关节力矩 | MPC + 层级 QP |
| 移动操作（MoManipVLA） | 上层：底盘+臂的联合轨迹；下层：WBC | 双层轨迹优化 |
| 轨迹平滑 | 样条/多项式拟合 | 闭式解 或 小规模 QP |
| 灵巧手抓取 | 接触力分配 | QP（二次锥约束） |
