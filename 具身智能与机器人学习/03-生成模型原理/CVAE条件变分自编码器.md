# CVAE 条件变分自编码器

> **一句话**：在给定条件 $c$（如观测）下生成多样化输出 $x$（如动作）的生成模型，用来建模「一对多」的多模态映射。

## 为什么需要 CVAE？（动机——行为克隆的核心难题）

机器人动作是**一对多**的：同一个「观测 + 指令」下，往往有多种合法动作。

```
        左绕 →→→
起点 ═══════════════ 目标          （两条路都对）
        右绕 →→→
```

如果用普通回归（MSE）训练策略，网络会学到一个「**平均动作**」——恰好从障碍物中间穿过去，直接碰撞。

CVAE 的解法：引入**隐变量 $z$** 承载「哪种模式」（左绕还是右绕）。给定观测 $c$，采样不同 $z$ 就得到不同但都合法的动作。**这正是行为克隆（ACT）能处理多模态演示的原因。**

> 机器人领域几乎所有「VAE」算法底层都是 CVAE——必须根据环境生成动作 $p(\text{action}\mid\text{state})$。

## 怎么工作（核心机制）

```
            训练阶段                              推理阶段
观测 c ─┐                                      观测 c ─┐
        ├→ [Encoder] → μ,σ ─→ z ~ N(μ,σ)               │   z ~ N(0,1)（先验采样）
真实动作 x ┘                                        └→ [Decoder] → 预测动作 x̂
               │                                          ↑
               └── z 与 c 一起送入 Decoder 重建 x ─────────┘
```

- **Encoder（只在训练用）**：根据观测 $c$ + 真实动作 $x$，推断隐变量 $z$ 的后验 $q_\phi(z|c,x)$
- **Decoder（训练+推理都用）**：根据 $c$ + $z$ 生成动作 $p_\theta(x|c,z)$
- **训练损失**：重建损失 + KL 正则

$$\mathcal{L} = \underbrace{\|x - \hat{x}\|^2}_{\text{重建}} + \beta \cdot \underbrace{D_{\text{KL}}\big(q_\phi(z|c,x)\,\|\,p(z)\big)}_{\text{KL 正则，}p(z)=N(0,1)}$$

- KL 正则把 $z$ 压到标准正态，**推理时才能直接从 N(0,1) 采样**（而不是依赖 encoder）

## 在模型中的角色（SOTA 关联）

| 工作 | 领域 | CVAE 解决什么 |
|---|---|---|
| **ACT** (RSS'23) | 模仿学习 | 动作多模态歧义（左绕/右绕）：训练用 encoder 推断 z，推理从 N(0,1) 采样 z |
| **6-DOF GraspNet** | 抓取 | 多角度无碰撞抓取采样 |
| **MPNet** (IJRR) | 运动规划 | 启发式采样分布 |
| **Trajectron++** (ECCV) | 轨迹预测 | 意图不确定性 |

## 工程化实现

- **重参数化**：$z = \mu + \sigma \odot \epsilon,\ \epsilon\sim N(0,1)$，让采样可微分（否则无法反传）
- **β-VAE 权重**：$\beta>1$ 更强正则 → 隐空间更规整但重建质量下降；ACT 用 $\beta$ 平衡两者
- **KL anneal（退火）**：训练初期 $\beta$ 从 0 渐增，避免一开始 KL 压太狠导致「后验塌缩」（encoder 输出常数）
- **后验塌缩**：若 decoder 太强，encoder 学不到有用信息（$z$ 被忽略），需调 $\beta$ 或 anneal

## 局限

- **高斯单峰假设**：CVAE 假设 $z$ 先验是高斯 → 隐空间「连续单峰」，对**高度多模态/复杂分布**（如精细操作的动作分布）表达力不足 → 催生了 Diffusion Policy / Flow Matching
- **推理快**（<5ms，一次前向）适合高频控制；但质量上限不如扩散
