# VAE 与 KL 散度深入理解

> **一句话**：VAE 把数据压缩成一个**概率分布**（而非固定向量），从而能「从分布里采样」生成新数据；KL 散度负责把这个分布约束成规整的标准正态。

## 为什么需要 VAE？（动机）

普通自编码器（AE）把图像压成一个**确定的向量** $z$ 再还原，但它有两个致命问题：

1. **隐空间不连续**：两个样本的 $z$ 之间是「无人区」，采样一个中间值会得到乱码
2. **不能生成**：只能「编码→解码」，无法从隐空间随机采样生成新样本

VAE 的解法：让 encoder 输出**均值 $\mu$ 和方差 $\sigma$**（一个分布），再从分布里采样 $z$。配合 KL 正则，把整个隐空间「挤」成连续、可插值的标准正态 → 任意采样都有意义。

> **直觉类比（门牌号）**：$\mathcal{N}(0,1)$ 是「规矩」（每个 $z$ 该住哪片区域），encoder 输出的 $\mu,\sigma$ 是「答案」（这个样本实际住哪）。
> - 跑步样本 → $\mu=[0.8,-0.5,\dots]$
> - 深蹲样本 → $\mu=[-0.9,0.3,\dots]$
>
> 若没有 KL 约束，encoder 会走捷径把门牌号设到 $\pm10000$，中间全是无人区——采样就崩了。

## 怎么工作（核心机制）

```
x ──→ [Encoder] ──→ μ, σ ──→ z = μ + σ⊙ε ──→ [Decoder] ──→ x̂
                              ε ~ N(0,1)
```

- **重参数化技巧**：$z = \mu + \sigma \odot \epsilon$。采样 $\epsilon$ 与网络参数无关，梯度能穿过 $z$ 反传到 $\mu,\sigma$（否则「从分布采样」这一步不可微）
- **损失**：重建损失 + KL 正则

$$\mathcal{L} = \|x-\hat{x}\|^2 + \beta \cdot D_{\text{KL}}\big(\mathcal{N}(\mu,\sigma^2)\,\|\,\mathcal{N}(0,1)\big)$$

## KL 散度在这里干什么

$$D_{\text{KL}} = \frac{1}{2}\sum_{i=1}^d(\mu_i^2 + \sigma_i^2 - 1 - \ln\sigma_i^2)$$

| 项 | 作用 |
|---|---|
| $\mu^2$ | 推动 $\mu\to 0$（各样本住回原点附近） |
| $\sigma^2$ | 推动 $\sigma^2\to 1$（方差统一） |
| $-\ln\sigma^2$ | 防止 $\sigma^2\to 0$ 塌缩（趋 0 时这项 → +∞） |

**两个方向的坍缩**（都是病态的）：

- $\sigma\to 0$：encoder 输出确定值，退化回 AE（不能采样）
- $\mu\to 0,\sigma\to 1$：所有样本挤成同一个标准正态，$z$ 失去区分度（后验塌缩）

KL 正则在这两者之间找平衡：**有区分度，但又连续可插值**。

## 在模型中的角色（SOTA 关联）

- **ACT/CVAE** 的隐变量就是 VAE 的 $z$——代表「动作模式」（左绕/右绕），见 [[CVAE条件变分自编码器]]
- **VQ-VAE** 是它的离散化变体：把连续的 $\mu,\sigma$ 换成「离散码本」，见 [[VQ-VAE与动作Token化]]

## 工程化实现

- **重参数化**是 VAE 能训练的关键，几乎所有框架都内置
- **KL 权重 $\beta$**：$\beta<1$ 弱正则（重建更准但隐空间乱），$\beta>1$ 强正则（隐空间规整但模糊），$\beta$-VAE 用于解耦
- **后验塌缩（posterior collapse）**：decoder 太强时忽略 $z$，encoder 输出变成无关噪声；对策是 KL anneal、free-bits（限制 KL 下限）

## 局限

- 高斯先验 → 隐空间单峰，难以建模复杂多模态分布（→ CVAE 加条件、Diffusion 彻底摆脱高斯假设）
