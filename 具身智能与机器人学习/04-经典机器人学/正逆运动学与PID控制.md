# 正逆运动学与 PID 控制

> **定位**：人形端到端栈 **L2/L5 的落地**。策略输出"目标位姿"，把它变成电机指令的最后一段路就是：**IK 解关节角 → 控制器（PID/阻抗）出力矩**。这是所有物理机器人的执行底线。
>
> 前置：[[SE3与SO3空间变换]] [[机器人动力学基础]]。关联：[[从策略输出到真机执行]] [[人形硬件与系统构成]]。

## 一、正运动学 FK：关节角 → 末端位姿

**问题**：已知关节角 $\boldsymbol{\theta}=(\theta_1,\dots,\theta_n)$，求末端位姿 $\mathbf{T}_{\text{EE}}$。

**DH 参数法**：给每个关节建立坐标系，用 4 个参数描述相邻关节的变换，逐级链式相乘：

$$\mathbf{T}_{\text{EE}} = \mathbf{T}_1(\theta_1)\,\mathbf{T}_2(\theta_2)\cdots\mathbf{T}_n(\theta_n)$$

| DH 参数 | 含义 |
|--------|------|
| $a$（连杆长度） | 相邻 z 轴间距离 |
| $\alpha$（连杆扭转） | 相邻 z 轴夹角 |
| $d$（关节偏置） | 沿 z 轴的位移 |
| $\theta$（关节角） | 绕 z 轴的旋转（旋转关节的变量） |

**直觉**：FK 是"从根到叶"正向推——每个关节的变换叠加，最终得到末端在世界/基座系的位置姿态。这是 IK 的逆过程，也是手眼标定、仿真里机器人位姿的来源。

## 二、逆运动学 IK：目标位姿 → 关节角

**问题**：已知目标末端位姿，反求关节角 $\boldsymbol{\theta}$。这是策略落地的核心（策略给位姿，机器人要关节角）。

### 2.1 雅可比迭代（数值 IK 主流方法）

末端速度与关节速度的关系：$\dot{\mathbf{x}} = \mathbf{J}(\boldsymbol{\theta})\,\dot{\boldsymbol{\theta}}$，其中 $\mathbf{J}$ 是雅可比（末端位姿对关节角的偏导）。离散化后：

$$\Delta\boldsymbol{\theta} = \mathbf{J}^+\Delta\mathbf{x}$$

- $\mathbf{J}^+$：雅可比的伪逆（$\mathbf{J}$ 通常非方阵，用最小二乘伪逆 $\mathbf{J}^+=\mathbf{J}^T(\mathbf{J}\mathbf{J}^T)^{-1}$）
- **迭代**：从当前关节角出发，反复"算误差 → 用 J⁺ 修正 → 逼近目标"，直到误差小于阈值

### 2.2 IK 的四大坑

| 问题 | 表现 | 对策 |
|------|------|------|
| **多解** | 同一末端位姿对应多组关节角（肘上/肘下） | 选离当前最近的解（最小位移） |
| **奇异点** | 某些姿态下 $\mathbf{J}$ 降秩，J⁺ 爆炸 | **阻尼最小二乘**（加 $\lambda^2\mathbf{I}$ 正则） |
| **关节限位** | 解超出物理范围 | 解投影回限位内 |
| **不可达** | 目标太远 | 报错/取最近可达解 |

## 三、PID 控制：让关节"听话"

策略/IK 给出目标关节角，PID 负责把关节**真正驱动过去**：

$$u(t) = K_p e(t) + K_i\int_0^t e(\tau)d\tau + K_d\frac{de(t)}{dt}$$

其中 $e(t)=$ 目标值 $-$ 实际值（误差）。

| 项 | 作用 | 调大之后 |
|----|------|---------|
| **P**（比例） | 响应当前误差 | 快，但过大振荡 |
| **I**（积分） | 消除稳态误差（累积历史误差） | 消静差，但过大过冲 |
| **D**（微分） | 抑制振荡（预测趋势、加阻尼） | 稳，但放大噪声 |

### 离散化（实际代码里长这样）

$$u_k = K_p e_k + K_i\sum_{j=0}^{k} e_j\Delta t + K_d\frac{e_k - e_{k-1}}{\Delta t}$$

### 调参直觉（经验顺序）

1. 先只调 P：从 0 往上加，直到快速响应但轻微振荡
2. 加 D：抑制振荡（D 对噪声敏感，先低通滤波误差）
3. 最后加 I：消除稳态误差（I 最容易引起过冲，谨慎加）

### 关节空间 vs 笛卡尔空间 PID

| 方式 | 怎么控制 | 适用 |
|------|---------|------|
| 关节空间 PID | 每关节独立跟踪目标角 | 简单、IK 之后用 |
| 笛卡尔空间 PID | 末端误差 × $\mathbf{J}^T$ 映射到关节力矩 | 直接跟踪末端位姿、阻抗控制 |

## 四、阻抗控制：为什么不能纯 PID

纯位置 PID 假设"关节角度精确到位"，但抓取、接触、人机协作时**位置误差会变成巨大的接触力**（撞到桌子还硬推）。阻抗控制让机械臂表现得像**弹簧-阻尼-质量**系统，柔顺地适应外力：

$$\boldsymbol{\tau} = \mathbf{J}^T(\mathbf{K}_d\mathbf{e} + \mathbf{D}_d\dot{\mathbf{e}}) + \mathbf{g}(\boldsymbol{\theta})$$

- $\mathbf{K}_d$：刚度（"弹簧"），$\mathbf{D}_d$：阻尼（"减震器"），$\mathbf{g}$：重力补偿
- **阻抗 vs 导纳**：阻抗 = 测位移出力的（机械臂常用）；导纳 = 测力出位移的（适合力传感器）

**人形为什么需要**：走路落地冲击、抓取柔顺都靠它（见 [[人形硬件与系统构成]] 的力矩控制）。

## 五、完整控制链路（频率金字塔）

```
策略 → 目标位姿（10-50Hz）→ IK → 目标关节角 → PID/阻抗（1000Hz+）→ 电机 → 编码器反馈 → 闭环
```

**关键**：策略想得慢（10-50Hz），PID 跑得快（1kHz）——高层给目标，低层闭环执行。这个分工贯穿整个具身系统（见 [[从策略输出到真机执行]]、[[人形硬件与系统构成]]）。
