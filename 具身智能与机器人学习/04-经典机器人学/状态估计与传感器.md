# 状态估计与传感器

> **定位**：人形端到端栈 **L4**。RL/VLA 策略的输入是"状态"（关节角、速度、姿态、质心位置），但机器人没有"状态传感器"——只有关节编码器、IMU 这些**原始测量**。状态估计回答：**怎么从有噪声的传感器读数里，得到可靠的机器人状态**。
>
> 前置：[[机器人动力学基础]]（状态怎么演化）。关联：[[人形仿真与RL训练]]（RL 观测怎么选）。

## 一、传感器：机器人"知道"自己的原始来源

| 传感器 | 测什么 | 特点 |
|--------|--------|------|
| **关节编码器** | 关节角 $q$（绝对/增量） | 直接、高频；差分得速度 $\dot{q}$ 会放大噪声 |
| **IMU（惯性测量单元）** | 角速度 $\omega$、线加速度 $a$ | 高频、漂移大；含重力分量 |
| **足底力/接触传感器** | 接触力/是否着地 | locomotion 关键（判断支撑相） |
| **相机/RGB-D** | 视觉/深度 | 定位、避障；不是"本体感觉" |

**关键矛盾**：编码器能测关节角但测不到"身体相对世界的姿态"；IMU 能测姿态变化但积分会漂移——**两个都有缺陷，融合起来才可靠**。这就是状态估计存在的意义。

## 二、为什么"直接积分"会崩

- IMU 姿态：$\theta_{t+1} = \theta_t + \omega_t \Delta t$ —— 每步都带一点点误差，误差**累积**，几十秒后姿态完全漂走
- 编码器速度：$\dot{q} = (q_{t+1}-q_t)/\Delta t$ —— 差分把微小噪声放大成速度噪声

**结论**：单靠任何一种传感器都不行，需要**用模型（动力学/运动学）+ 多传感器测量互相校正**。

## 三、卡尔曼滤波：状态估计的核心算法（教学）

卡尔曼滤波（KF）用两件事估计状态 $\mathbf{x}$：

1. **预测步**：用模型"猜"下一步状态（先验）
2. **更新步**：用传感器测量"纠"这个猜测（后验）

### 预测步（模型驱动）

$$\hat{\mathbf{x}}_{t|t-1} = \mathbf{F}\hat{\mathbf{x}}_{t-1} + \mathbf{B}\mathbf{u}_{t-1}, \qquad \mathbf{P}_{t|t-1} = \mathbf{F}\mathbf{P}_{t-1}\mathbf{F}^T + \mathbf{Q}$$

### 更新步（测量校正）

$$\mathbf{K} = \mathbf{P}_{t|t-1}\mathbf{H}^T(\mathbf{H}\mathbf{P}_{t|t-1}\mathbf{H}^T + \mathbf{R})^{-1}$$

$$\hat{\mathbf{x}}_t = \hat{\mathbf{x}}_{t|t-1} + \mathbf{K}(\mathbf{z}_t - \mathbf{H}\hat{\mathbf{x}}_{t|t-1})$$

| 符号 | 含义 | 直觉 |
|------|------|------|
| $\mathbf{F}$ | 状态转移矩阵 | 模型怎么演化（如 $\theta_{t+1}=\theta_t+\omega\Delta t$） |
| $\mathbf{H}$ | 观测矩阵 | 测量怎么对应状态 |
| $\mathbf{Q}$ | 过程噪声协方差 | 模型有多不可信 |
| $\mathbf{R}$ | 测量噪声协方差 | 传感器有多不可信 |
| $\mathbf{K}$ | 卡尔曼增益 | **信模型还是信测量的加权系数** |

**一句话直觉**：KF = "模型猜一步，传感器纠一下"，用协方差 $\mathbf{P}$ 表达"我现在有多确定"，$\mathbf{K}$ 自动决定更信谁。$\mathbf{Q}$ 大 → 更信测量；$\mathbf{R}$ 大 → 更信模型。

### 非线性怎么办：EKF / UKF

机器人动力学非线性（$\theta$ 在旋转群上），线性 KF 不够 → 扩展卡尔曼（EKF，一阶泰勒近似）或无迹卡尔曼（UKF，采样近似）。概念上"预测-更新"框架不变，只是把线性化/采样处理了。

### 简单替代：互补滤波

姿态估计常用更简单的**互补滤波**：对 IMU 角速度积分的高频部分 + 加速度计（重力方向）的低频部分，按频率互补加权——没有 KF 严谨但实现极简单，很多轻量机器人先用它。

## 四、人形机器人最需要估计什么

| 状态量 | 来源 | 用途 |
|--------|------|------|
| 关节角 $q$、角速度 $\dot{q}$ | 编码器 | 策略/控制的基本输入 |
| 躯干姿态（四元数/旋转矩阵） | IMU + KF | 判断"我是不是倒了" |
| **重力方向投影** | IMU | **locomotion RL 的关键观测**——让策略知道"哪是下" |
| 质心位置/速度 | KF（结合动力学） | WBC/MPC 的输入（见 [[人形机器人全身控制-WBC与MPC]]） |
| 接触状态（哪只脚着地） | 足底力传感器 | 步态相判断 |

## 五、在具身学习中的落点

- **RL 观测设计**：Isaac 仿真里状态"免费"，但 sim-to-real 时真机只有编码器+IMU → **观测必须只用真机可测的量**（这是人形 RL 的隐藏大坑，见 [[人形仿真与RL训练]]）
- **VLA 本体感觉**：把 $q, \dot{q}$ 编码成本体 token 喂给策略
- **真机部署**：策略输出关节目标，实际闭环靠低层控制用估计的状态反馈（见 [[从策略输出到真机执行]]）
