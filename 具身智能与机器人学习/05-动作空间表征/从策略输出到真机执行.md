# 从策略输出到真机执行

策略输出的"动作块"不是最终执行量，要经 IK（若出 EEF）→ 底层控制器 → 电机 的闭环才驱动真机。

> 直觉类比：策略像导航软件说"去 3 楼 302"，IK 是电梯/楼梯，把"去哪"翻译成"每一步怎么迈"。

## 为什么总有人困惑

- **CVAE 不是"只生成末端轨迹"**。CVAE 只是生成引擎（变分自编码采样），生成什么空间取决于策略 Decoder 的输出层设计：输出层写关节角就出关节角，写 EEF 位姿就出 EEF。空间是 Decoder 决定的，不是 CVAE 决定的。
- **出 EEF 位姿的策略必须过 IK**。真机电机只认关节角（或关节力矩），"往左 5cm"这种末端表述必须由 IK 反算成每个关节转多少，才能喂给底层控制器。

## 怎么工作：两条路径

```
观测(图像+本体) → 策略(CVAE/扩散/VLA) → 动作块
  ├─ 关节空间直出(ACT) ────────────────┐
  └─ EEF位姿(DiffusionPolicy/VLA) → IK(Δθ=J⁺Δx) ┐
                                          ↓
                           PID/阻抗控制(1kHz) → 电机 → 编码器反馈闭环
```

- 路径一：ACT 直接输出 14 维绝对关节角，跳过 IK，绕过奇异点问题，代价是换臂必重新训练。
- 路径二：Diffusion Policy / RT-2 / OpenVLA 输出 EEF 相对增量，靠 IK 落地，换臂可迁移。

## IK 核心

$$\Delta\boldsymbol{\theta} = \mathbf{J}^+\Delta\mathbf{x}$$

雅可比伪逆求解。难点：多解（选最近解）、奇异点（阻尼最小二乘）、关节限位（投影）、不可达（放弃）。

## 控制频率分层

| 层 | 频率 | 职责 |
|---|---|---|
| 策略 | 10-50Hz | 出动作块 |
| IK | 50-100Hz | 末端→关节 |
| 底层控制 | 1kHz+ | PID/阻抗 → 电机 |

## 动作空间对比

| 策略 | 输出 | 是否过IK |
|---|---|---|
| ACT | 关节角(绝对) | 否 |
| Diffusion Policy | EEF相对增量 | 是 |
| RT-2 / OpenVLA | EEF相对增量 | 是 |

## 落地要点

- **IK 求解器选型**：六轴用解析法（快、有闭式解）；冗余臂或自由任务用数值迭代（通用、可加约束）。
- **奇异点阻尼最小二乘**：$\mathbf{J}^+ = \mathbf{J}^T(\mathbf{J}\mathbf{J}^T + \lambda^2\mathbf{I})^{-1}$，牺牲一点精度换稳定性。
- **时域平滑融合**：相邻 chunk 有重叠时，重叠区做指数加权平均再执行，避免跳变。
