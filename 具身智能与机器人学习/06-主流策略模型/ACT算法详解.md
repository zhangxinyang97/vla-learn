# ACT：Action Chunking with Transformers

> **定位**：人形端到端栈 **L6 策略层**的第一个里程碑。Stanford ALOHA（RSS 2023）——低成本双臂操作的代表作，LeRobot/ALOHA 生态的默认策略之一。本篇教学目标：**搞懂"为什么是 CVAE + 为什么预测一整块动作"，而不只是背架构图**。
>
> 前置：[[CVAE条件变分自编码器]] [[动作空间表征总览]] [[Transformer与注意力机制]]。对比：[[Diffusion-Policy详解]]。

## 一、问题背景：模仿学习的两个老毛病

模仿学习（看演示学）的两大痛点，ACT 针对性地解决：

1. **复合误差**：逐帧预测时，每帧一点小偏差，后续越错越远（漂移）
2. **多模态动作**：同一观测下，正确动作可能有好几种（杯子可从左/右绕过去抓）——单峰高斯分布学不好这种"多答案"

ACT 的两张王牌正好对应：**Action Chunking** 治复合误差，**CVAE** 治多模态。

## 二、Action Chunking：一次预测 100 帧

不是逐帧预测下一步，而是**一次输出一个动作块** $[a_t, a_{t+1}, \dots, a_{t+K-1}]$，K=100@50Hz = 2 秒。

- **抗漂移**：块内动作靠 Transformer 自注意力保持时间一致性，不会像逐帧那样"一步错步步错"
- **天然平滑**：整块联合生成，比逐帧拼接更连贯
- **代价**：块太长会慢、太短又回到逐帧的老路——K 是个权衡

## 三、CVAE：多模态的答案（核心）

### 3.1 为什么用 VAE 的隐变量

- 纯回归 $\pi(a|o)$ 是**单峰**的（预测一个"平均动作"），学不了"从左边还是右边抓"
- CVAE 引入隐变量 $z$：不同的 $z$ 对应**不同的动作模式**，把多模态分布"拆"成条件单峰

### 3.2 训练 vs 推理（不对称，关键！）

| | Encoder | Decoder |
|---|---|---|
| **训练** | 从**演示动作**里推断 $z$（μ,σ），让 z 记住"这条演示是哪种模式" | $z$ + 观测 → 预测动作，算重建损失 |
| **推理** | **不使用** | 从 $N(0,1)$ 随机采样 $z$ → 生成动作 |

**为什么推理不用 encoder**：真实部署时没有"演示动作"可看，只能从标准正态里随机抽 $z$。所以训练时必须用 KL 把 $z$ 压向 $N(0,1)$，否则推理时抽的 $z$ 与训练时 encoder 给的 $z$ 分布对不上。

### 3.3 损失函数

$$\mathcal{L} = \underbrace{\mathcal{L}_{\text{recon}}}_{\text{L1 重建}} + \beta \cdot \underbrace{D_{\text{KL}}\big(q(z|x)\parallel N(0,1)\big)}_{\text{隐变量正则}}$$

- L1 重建：动作预测准（L1 对偶发大偏差稳健，见 [[Policy与损失函数]]）
- $\beta$ 控 KL 权重（β-VAE 思路）：β 大 → 隐空间更贴近标准正态、更"可采样"，但可能丢信息

## 四、完整数据流

```
观测图像 → ResNet → 视觉特征 ─┐
关节状态 → MLP → 本体特征 ────┤→ Transformer Decoder → [a_0, ..., a_99]
隐变量 z ~ N(0,1) → 拼接 ─────┘
```

- 视觉塔：ResNet-18（低成本，够用）
- 动作空间：**14 维绝对关节角**（双臂 7×2）
- 本体感觉：当前关节状态（给策略"我现在是什么姿态"）

## 五、与 Diffusion Policy 对比

| | ACT（CVAE） | Diffusion Policy |
|---|---|---|
| 动作分布 | 隐变量 + 单峰高斯 | **任意多模态分布** |
| 精细操作 | 一般 | **优秀** |
| 推理速度 | <5ms（快） | 10-100ms（DDIM 10 步 ≈ 20ms） |
| 数据需求 | 中 | 更少 |
| 适合 | 双臂粗操作、快速部署 | 精细/接触丰富操作 |
