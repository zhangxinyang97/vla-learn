# 主流代码库与动手路线

> **为什么需要？** 知识地图是"读"，这篇是"做"的入口。目标：一周内跑通第一个扩散策略，两周内自己采数据训练 ACT，之后按需深挖。**理论看到 [[Diffusion-Policy详解]] / [[ACT算法详解]] 即可动手，不必等全部读完。**

## 一、代码库地图

| 代码库 | 维护方 | 内容 | 适合 |
|--------|--------|------|------|
| **LeRobot** | HuggingFace | ACT / Diffusion Policy / Pi0 实现 + Push-T 复现 + 数据集规范（Zarr） | **首选入口，一站式** |
| diffusion_policy 官方 | Columbia | 2D/3D 扩散策略，Push-T + RoboMimic | 研究复现 |
| ACT 官方（ALOHA） | Stanford | 双臂真机 ACT，自采数据管线 | 有真机时 |
| robomimic | Stanford | 算法库（BC/BC-RNN/IRL/RL）+ RoboMimic 基准 | 算法对比研究 |
| DP3 官方 | THU/清华 | 3D 点云扩散策略 | 3D 路线 |
| Isaac Lab / Gym | NVIDIA | 大规模并行 RL 训练 | 仿真 RL |

> **提醒**：π0 无官方开源，可跑 LeRobot 的 Pi0 复现（基于 OpenVLA 底座 + Flow Matching 头）；本地 GPU 显存有限时优先 LeRobot 的 ACT/DP。

## 二、环境准备（30 分钟）

```bash
# Linux/WSL 或 Windows 均可；建议 Python 3.10 + PyTorch 2.x
conda create -n lerobot python=3.10 -y
conda activate lerobot
pip install lerobot  # 或 git clone + pip install -e .
```

- **无 GPU 也能学**：Push-T 用 CPU 可跑（慢 3-5 倍，适合验证流程）；正式训练建议 ≥8GB 显存
- 真机控制需要 ROS2 或厂家 SDK，见 [[仿真引擎与ROS2部署]]

## 三、动手里程碑（5 步）

```
M1  跑通 Push-T 训练 Diffusion Policy（LeRobot）          ≈ 半天
    lerobot/examples/7_get_started_with_pusht.py 一键式
M2  看懂训练日志：loss 曲线、评估覆盖率、checkpoint 推理   ≈ 半天
M3  RoboMimic 仿真训练 ACT / DP（lift → can）             ≈ 1-2 天
M4  ALOHA Sim 双臂插入（ACT 官方配置）                     ≈ 1-2 天
M5  真机闭环：SO-100/UR5 + 遥操作采集 → 训练 → 部署        ≈ 1-2 周
    （数据管线见 [[遥操作与数据工程]]，标定见 [[相机模型与手眼标定]]）
```

**M5 的隐藏关卡**：数据质量 > 数据量（采集时手要稳、轨迹要覆盖失败恢复）；标定不齐 → 策略在真机"差一点"。

## 四、踩坑速查

| 坑 | 表现 | 对策 |
|----|------|------|
| 动作空间不一致 | 训练 loss 正常但真机乱动 | 确认 EEF 增量 vs 绝对、关节 vs 笛卡尔（见 [[动作空间表征总览]]） |
| 频率不匹配 | 真机抖动 | 推理频率（10-50Hz）与训练数据采集频率一致 |
| 相机标定漂移 | 抓取位置系统性偏移 | 重做手眼标定 |
| 过拟合演示 | 换物体就失败 | 增加数据多样性 + 域随机化 |
| 显存不足 | OOM | 降 batch/降图像分辨率/用 LoRA |
