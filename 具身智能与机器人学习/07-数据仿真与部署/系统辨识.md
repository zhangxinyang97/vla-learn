# 系统辨识

> 系统辨识是 Sim-to-Real 的测量桥梁——从真实数据中提取物理参数，注入仿真模型，缩小动力学 Gap。

## 为什么需要系统辨识

仿真→真实的 Gap 根源：**仿真模型参数不准确**。仿真引擎（MuJoCo / Isaac Sim）的动力学方程正确，但若输入的质量、摩擦、惯量与实际机器人不同，策略必然迁移失败。

系统辨识解决：**真机运行激励轨迹 → 采集状态-力矩数据 → 拟合参数 → 注入仿真**。

## 刚体动力学参数模型

机器人标准动力学方程（拉格朗日形式）：

$$\mathbf{M}(\mathbf{q})\ddot{\mathbf{q}} + \mathbf{C}(\mathbf{q},\dot{\mathbf{q}})\dot{\mathbf{q}} + \mathbf{g}(\mathbf{q}) = \boldsymbol{\tau}$$

| 符号 | 含义 | 维度 |
|------|------|------|
| $\mathbf{M}(\mathbf{q})$ | 惯性矩阵（质量分布） | $n \times n$ |
| $\mathbf{C}(\mathbf{q},\dot{\mathbf{q}})$ | 科里奥利力 + 离心力矩阵 | $n \times n$ |
| $\mathbf{g}(\mathbf{q})$ | 重力项 | $n \times 1$ |
| $\boldsymbol{\tau}$ | 关节力矩 | $n \times 1$ |
| $\mathbf{q}$ | 关节位置 | $n \times 1$ |

关键性质：**动力学方程对惯性参数线性**（需重新参数化到最小参数集）：

$$\mathbf{Y}(\mathbf{q},\dot{\mathbf{q}},\ddot{\mathbf{q}})\,\boldsymbol{\pi} = \boldsymbol{\tau}$$

其中 $\mathbf{Y}$ 为回归矩阵（由轨迹决定），$\boldsymbol{\pi}$ 为待辨识的物理参数向量（质量、质心、惯量、摩擦系数）。

## 最小二乘辨识

### 批量最小二乘

采集 $N$ 帧数据 $\{(\mathbf{Y}_k, \boldsymbol{\tau}_k)\}_{k=1}^N$，堆叠为：

$$\bar{\mathbf{Y}} = \begin{bmatrix}\mathbf{Y}_1 \\ \vdots \\ \mathbf{Y}_N\end{bmatrix},\quad \bar{\boldsymbol{\tau}} = \begin{bmatrix}\boldsymbol{\tau}_1 \\ \vdots \\ \boldsymbol{\tau}_N\end{bmatrix}$$

最小化残差平方和 $\min_{\boldsymbol{\pi}}\|\bar{\mathbf{Y}}\boldsymbol{\pi} - \bar{\boldsymbol{\tau}}\|^2$，伪逆解：

$$\hat{\boldsymbol{\pi}} = (\bar{\mathbf{Y}}^T\bar{\mathbf{Y}})^{-1}\bar{\mathbf{Y}}^T\bar{\boldsymbol{\tau}}$$

> 激励轨迹需充分"激励"所有参数——避免 $\bar{\mathbf{Y}}^T\bar{\mathbf{Y}}$ 奇异。常用傅里叶级数轨迹。

### 递推最小二乘 (RLS)

每来一帧新数据 $(\mathbf{Y}_t, \boldsymbol{\tau}_t)$，增量更新，无需存全部历史：

$$\begin{aligned}
\mathbf{K}_t &= \mathbf{P}_{t-1}\mathbf{Y}_t^T(\lambda\mathbf{I} + \mathbf{Y}_t\mathbf{P}_{t-1}\mathbf{Y}_t^T)^{-1} \\[4pt]
\hat{\boldsymbol{\pi}}_t &= \hat{\boldsymbol{\pi}}_{t-1} + \mathbf{K}_t(\boldsymbol{\tau}_t - \mathbf{Y}_t\hat{\boldsymbol{\pi}}_{t-1}) \\[4pt]
\mathbf{P}_t &= \frac{1}{\lambda}(\mathbf{I} - \mathbf{K}_t\mathbf{Y}_t)\mathbf{P}_{t-1}
\end{aligned}$$

| 符号 | 含义 |
|------|------|
| $\mathbf{P}_t$ | 协方差矩阵（参数估计不确定度） |
| $\mathbf{K}_t$ | 卡尔曼增益（新息权重） |
| $\lambda \in (0,1]$ | 遗忘因子（$\lambda<1$ 适应时变参数） |
| $\boldsymbol{\tau}_t - \mathbf{Y}_t\hat{\boldsymbol{\pi}}_{t-1}$ | 预测误差（新息 innovation） |

### RLS Python 伪码

```python
def rls_identify(Y_seq, tau_seq, lam=0.99):
    """递推最小二乘在线参数估计"""
    n_params = Y_seq[0].shape[1]
    pi = np.zeros((n_params, 1))        # 参数估计
    P = np.eye(n_params) * 1e6          # 初始协方差（大 = 先验弱）

    for Y_t, tau_t in zip(Y_seq, tau_seq):
        # 卡尔曼增益
        S = lam * np.eye(tau_t.shape[0]) + Y_t @ P @ Y_t.T
        K = P @ Y_t.T @ np.linalg.inv(S)

        # 更新参数估计
        innovation = tau_t - Y_t @ pi
        pi = pi + K @ innovation

        # 更新协方差
        P = (np.eye(n_params) - K @ Y_t) @ P / lam

    return pi, P
```

## 卡尔曼滤波联合估计

当参数随时间缓慢变化（如电机发热 → 电阻漂移），可将参数扩展为状态：

状态向量 $\mathbf{x}_t = [\mathbf{q}_t,\; \dot{\mathbf{q}}_t,\; \boldsymbol{\pi}_t]^T$，对非线性系统使用**扩展卡尔曼滤波 (EKF)** 或**无迹卡尔曼滤波 (UKF)**：

$$\begin{aligned}
\mathbf{x}_{t+1} &= f(\mathbf{x}_t, \mathbf{u}_t) + \mathbf{w}_t \quad (\mathbf{w}_t \sim \mathcal{N}(0,\mathbf{Q})) \\
\mathbf{z}_t &= h(\mathbf{x}_t) + \mathbf{v}_t \quad (\mathbf{v}_t \sim \mathcal{N}(0,\mathbf{R}))
\end{aligned}$$

| 符号 | 含义 |
|------|------|
| $f$ | 状态转移（含参数随机游走先验） |
| $h$ | 观测模型（编码器 → $\mathbf{q}$，力矩传感器 → $\boldsymbol{\tau}$） |
| $\mathbf{Q}$ | 过程噪声协方差（参数漂移幅度） |
| $\mathbf{R}$ | 观测噪声协方差（传感器精度） |

> EKF / UKF 优势：同时估计运动状态 + 物理参数，适用于在线自适应辨识。

## Neural Actuator 中的应用

[[NVIDIA-Sim-to-Real技术]] 的 Neural Actuator 训练前，需先辨识电机基础参数：

| 参数 | 物理意义 | 辨识方法 |
|------|----------|----------|
| 转子惯量 $J$ | 电机加速阻力 | 阶跃响应 → 时间常数 |
| 粘性摩擦 $B$ | 速度相关阻尼 | 恒速运行 → 力矩-速度斜率 |
| 库仑摩擦 $\tau_c$ | 静摩擦阈值 | 低速运行 → 力矩台阶 |
| 力矩常数 $K_t$ | 电流 → 力矩映射 | 堵转实验 → 力矩 / 电流 |

辨识出的参数作为 Neural Actuator MLP 的**物理先验**（输入特征归一化、损失函数正则化），MLP 仅需学习残差（真实 − 刚性体模型的差异），显著降低数据需求。

## 参数注入仿真

```
真机数据 → SysID → [J, B, τc, Kt, M, COM, I] → 仿真 XML → RL 训练 → Zero-shot 部署
```

辨识越准，仿真 Gap 越小，域随机化范围可收缩，策略训练更快更稳。
