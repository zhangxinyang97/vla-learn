# 2025–2026 VLA 新进展盘点

> **定位**：接在 [[端到端VLA模型盘点-上]] / [[端到端VLA模型盘点-下]] 之后，覆盖 2025 年的新一代 VLA。信息时效性强，**细节以 arXiv / 官方文档为准**，这里给的是骨架与趋势。

## 一、大厂闭源/半开源：数据 + 后训练

### Gemini Robotics / RT-X（Google DeepMind, 2025.03）

- 基于 **Gemini 2.0** 微调的 VLA 系列：Gemini Robotics（直接出动作）、Gemini Robotics-ER（具身推理，可生成"下一步该发生什么"的视频用于规划）
- 训练用 **RT-X** 数据集（OXE 汇总的跨机构真实机器人数据）+ Gemini 预训练
- 意义：**视频生成作为规划器**（世界模型式推理）进入产品化路线，见 [[世界模型与VLA集成]]

### GR00T N1（NVIDIA, 2025.03）

- **双系统**架构：System 1（快速动作生成）+ System 2（慢速语言推理，VLM 驱动）
- 开源权重，主打**人形机器人**；配套 Isaac/GR00T 数据飞轮（仿真合成数据，见 [[NVIDIA-Sim-to-Real技术]]）
- 意义：明确把"语言推理"与"动作执行"分系统——分层思想在大厂产品中的体现

## 二、开源社区：新一代开源 VLA

### π0.5（Physical Intelligence, 2025.06）

- 面向**多 embodiment 通用性**的 VLA 预训练模型（3B–7B），**开源权重**
- 主打 **post-training**：预训练得到通用基础，下游任务用少量数据微调（含跨机器人迁移）
- 架构延续 π0：Flow Matching 动作头（见 [[Flow-Matching流匹配]]）+ Transformer 骨干
- 意义：把"VLA 基础模型"像 LLM 一样"下载→微调"的范式落地

### π*（π-star, 2025）

- 多 embodiment、开源，基于 π0 架构扩展，主打跨本体迁移
- 与 RDT-1B / GR00T 一起代表"统一动作空间"路线的延续（见 [[双手操作与协调]] 的 RDT 讨论）

### OpenVLA 2 / Moto（NYU/Columbia/HF, 2025）

- 基于 **Llama 3 8B** 的新一代开源 VLA（替代 OpenVLA 的 Llama 2 7B 底座）
- 用 **DPO 偏好优化**提升动作质量；**Moto** 引入**潜在动作（latent actions）**：从视频里学习动作先验，让视觉编码器更强、对摄像头位姿更鲁棒
- 意义：开源 VLA 的"预训练数据规模 + 偏好对齐"竞赛开始

### HPT（CMU, 2024.11）

- **Heterogeneous Pre-trained Transformers**：跨 embodiment 预训练，把不同机器人的动作空间对齐到统一结构，再在下游微调
- 意义：通用具身基础模型的"体态无关"路线代表

## 三、RL 后训练：VLA 的"最后一公里"

| 工作 | 做法 | 意义 |
|------|------|------|
| **π0-RL**（PI） | 在 π0 上做 RL 微调（拆解任务、自动奖励） | VLA 从"模仿"到"自我改进" |
| **RST**（Google, 2025） | 用基础模型（PaLM2-E 等）生成奖励，对 RT-2 做 RL | 奖励来自语言模型 → 开放世界 RL |
| Isaac/仿真 RL 微调 | 仿真并行 RL 后接入 VLA 动作头 | 补足真实数据稀缺 |

**核心矛盾**：VLA 的泛化靠数据，精度靠 RL；两者都要，但 RL 稳定训练 VLA 仍是开放问题（见 [[端到端与分层架构之争]]）。

## 四、趋势总结（2025–2026）

1. **数据规模军备竞赛**：千→万→十万→百万小时，合成数据（仿真/视频）成为主要增量来源
2. **动作表征收敛到 Flow Matching**：π0 系 vs 自回归 Token 系（RT 系）并存，FM 因推理步数少占优
3. **后训练时代**：预训练基础模型（π0.5/GR00T）+ 少量数据微调 / RL 后训练，替代"从零训 VLA"
4. **视频与世界模型介入规划**：ER、视频生成即推理（见 [[世界模型与VLA集成]]）
5. **人形与灵巧成为主战场**：GR00T、整身 VLA（见 09 模块）、[[灵巧操作与触觉感知]]
