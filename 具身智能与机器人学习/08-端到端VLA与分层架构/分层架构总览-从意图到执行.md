# 分层架构总览：从意图到执行

> **定位**：人形端到端栈 **L6 分层路线**的教学级拆解。回答一个贯穿全库的问题：**一句"帮我把杯子拿过来"，是怎么一步步变成关节力矩的？** 把每一层、每层间的接口、误差如何传递讲清楚。
>
> 前置：[[VLA大模型]] [[端到端与分层架构之争]]。对比：[[端到端合一路径详解]]。展开：[[分层架构-VLM加运动规划]] [[分层架构-VLM加技能控制器]]。

## 一、一张图看懂整条链路

```
语言指令 "把杯子拿过来"
      ↓ ① 理解层
VLM：物体=杯子、目标=拿到我面前、场景约束
      ↓ ② 规划层（空间推理）
关键点/目标位姿/子任务序列（抓取点、放置点、路径约束）
      ↓ ③ 策略层（动作生成）
末端位姿目标 / 轨迹 / 技能选择（选"抓取技能"）
      ↓ ④ 执行层
运动规划（RRT）→ IK 求关节角 → 控制器（WBC/PID/阻抗）→ 电机
```

## 二、每一层干什么、用什么

| 层 | 输入 → 输出 | 代表方法 | 对应笔记 |
|----|------------|---------|---------|
| ① 理解层 | 语言/图像 → 任务语义 | VLM（GPT-4V/Gemini） | [[VLA大模型]] |

## 三、关键：层间接口是"人类定义的瓶颈"

分层架构的本质，是**在层与层之间插入人类可理解的中间表示**（目标位姿、关键点、技能名）：

- **好处**：每层可独立测试/替换；出错能定位到具体层；可解释（"它抓取点选错了" vs "黑盒乱动"）
- **代价**：接口是**信息压缩**——把连续的物理世界压成"一个目标位姿"，丢掉了接触力、物体柔性等细节 → **误差逐层累积**，高层错一点低层放大

> 这是理解 [[端到端与分层架构之争]] 的核心：分层 = 用信息压缩换可解释性与模块化；端到端 = 保留全部信息但失去可解释性。

## 四、教学案例：VoxPoser 怎么把语言变成轨迹

以 [[分层架构-VLM加运动规划]] 里的 VoxPoser 为例走一遍：

1. VLM 读指令 + 观测，输出两个 3D **价值图**：affordance map（"杯子附近值高"）+ constraint map（"避开障碍/桌面边缘"）
2. 把价值图当"势场"，用**模型预测控制/规划**生成机械臂末端轨迹（不训任何网络，直接用 LLM 的常识）
3. 轨迹交给 IK + 控制器执行

**要点**：VLM 没有输出具体数字关节角，而是输出"哪里好、哪里不能去"这种**可组合的中间表示**——这就是分层"接口"的典型形态。

## 五、误差怎么逐层累积（为什么分层会翻车）

```
理解错物体（杯子 vs 水壶）→ ② 目标位姿错 5cm
  → ③ 抓取姿态偏 → ④ 即使 IK 完美也抓空
```

分层架构的失败往往是**级联**的：上层小误差被下层忠实执行成"精确地抓错地方"。调试时先问"哪一层错了"：语义理解？位姿估计？还是执行？

## 六、分层在人形上的落地

人形全身的分层通常是：

```
VLA 高层（意图/任务）→ 全身策略（目标姿态/轨迹）→ WBC/MPC（全身力矩）→ 关节
```

对应 [[全身协同的VLA集成]]：VLA 出高层意图，WBC 统筹腿+臂+平衡，把"边走边拿"拆成可解的子问题。
