# 全身协同与移动操作：概览与学习路径

> **本模块**：补上「固定底座单臂/双臂」之外缺失的领域——真实机器人（人形、移动操作机器人）的全身动作协调。
> 覆盖底盘+臂的移动操作、人形全身控制理论（WBC/MPC）、双臂协调、VLA 与全身控制的分层集成、数据采集与仿真。

---

## 核心动机（为什么要有这个模块）

之前的笔记（[[VLA大模型]] 里的 ACT / Diffusion Policy / RT-2 / OpenVLA 等）几乎都是**固定底座 + 单臂或双臂**的桌面操作范式：底座不动，只有一条机械臂在操作台上完成 pick-place。但真实世界的机器人要么装着轮子/底盘，要么有两条腿——它们要一边移动一边抓取，一边保持平衡一边完成双臂动作。

一句话定义：**全身协同 = 底盘/腿 + 臂 + 躯干 + 平衡的同时协调。**

直觉类比：固定底座操作像「坐在办公桌前打字」，只有手在动；移动操作像「边走边端咖啡」，腿和手要配合；人形全身协同像「弯腰抱起地上的箱子」，腰、腿、臂、重心全部参与，任何一环掉链子都会摔。

## 演进对比：固定底座 → 移动操作 → 人形全身

| 维度 | 固定底座操作 | 移动操作 | 人形全身控制 |
|------|------------|---------|------------|
| 自由度 | 低（6-14，单/双臂） | 中（轮式底盘+臂，约 10-15） | 高（双腿+躯干+双臂，20-40+） |
| 平衡约束 | 无（底座锁死） | 弱（静态稳定为主） | 强（动态行走必须实时保持 ZMP/CoM） |
| 全身耦合 | 臂内耦合 | 底盘速度与臂末端速度协同 | 腿、臂、躯干、重心深度耦合 |
| 代表工作 | ACT / Diffusion Policy / RT-2 / OpenVLA | 移动底盘 + 机械臂的仓库取货 / 扫地机器人臂 | Atlas / Digit / Optimus / Figure 02，WBC+MPC 框架 |
| 核心难点 | 策略泛化 | 移动与操作的时序/空间协调 | 高维动作 + 稳定性约束 + 数据稀缺 |

一句话总结演进：**从「只动臂」到「动腿带动臂」再到「全身一起动」**，难度递进，也正好对应本模块由浅入深的学习顺序。

## 学习路径

### 路径 A：从最熟悉的场景切入（推荐起点）⭐
```
移动操作-底盘与臂协同 ← 与固定底座操作差异最小，轮式底盘先上手
  → 双手操作与协调 ← 从单臂策略自然延伸
  → 全身协同的VLA集成 ← 再回到 VLA 视角看分层
```
