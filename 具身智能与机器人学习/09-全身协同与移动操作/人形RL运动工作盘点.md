# 人形 RL 运动工作盘点

> **定位**：[[足式运动与步态]]、[[人形仿真与RL训练]] 的**具体落地实例**。"野外行走"不是一个单一模型，而是下面这一族 RL 方法在 Unitree G1/H1 上的产物。本篇按"训练源 → 控制模式 → sim-to-real 方案"给你一张可对号入座的表。
>
> **边界**：这里只收"**低层 RL 全身控制**"。上层人形大模型（VLA）如 **GR00T N1 / π0 / π0.5** 属于 08 模块（见 [[2025-VLA新进展盘点]]），不在本篇——GR00T 是"大脑"（理解+决策），本篇这些是"身体"（执行）。

## 一、总览表

| 工作 | 机构/年份 | 训练源 | 控制模式 | sim-to-real | 硬件 |
|------|----------|--------|---------|------------|------|
| **HOVER** | NVIDIA, 2024 | 纯仿真（Isaac Gym，约 300 万轨迹） | 多模式：动捕参考 / 根速度 / VR 头显 | 域随机化 | G1 / H1 / GR-1 |
| **ExBody** | CMU 等, 2023 | 人类动捕（AMASS）+ 仿真 RL | 参考姿态跟踪 | 域随机化 | H1 |
| **ExBody2** | 2024 | 动捕 + 策略蒸馏 | 参考姿态 + 多任务 | 蒸馏 + 域随机化 | G1 / H1 |
| **HumanPlus** | Stanford, 2024 | 人类影子示范 + RL | 全身影子 / 技能（HST/HIT） | 影子数据 + RL | H1 |
| **ASAP** | NVIDIA + CMU, 2025 | 仿真 RL | 敏捷全身动作（跳跃/转身/交叉步） | **delta action model** | G1 |

## 二、按"训练源"分类（关键差异）

| 训练源 | 代表 | 思路 | 优缺点 |
|--------|------|------|--------|
| **纯仿真 RL** | HOVER | 零真机数据，全靠仿真 + 随机化 | 无数据成本；sim-to-real 全压在随机化上 |
| **动捕参考** | ExBody / ExBody2 | 用人类动捕当"目标姿态"，RL 学跟踪 | 动作自然、有表现力；依赖动捕数据 |
| **影子示范** | HumanPlus | 人类实时戴动捕/头显"影随"机器人 | 数据最贴近真机；需要演示设备 |
| **sim-to-real 修复层** | ASAP | 叠加在任何 RL 策略上，修仿真与真机的 gap | 专治"仿真会、真机摔" |

## 三、sim-to-real 方案对比

| 方案 | 机制 | 代表 |
|------|------|------|
| **域随机化** | 训练时随机质量/摩擦/地形/扰动，逼策略鲁棒 | HOVER、ExBody |
| **delta action model** | 另训一个小网络输出"残差动作"，补偿仿真动力学偏差 | ASAP |
| **策略蒸馏** | 教师策略（仿真）蒸馏到学生策略（真机适配） | ExBody2 |
| **系统辨识** | 标定真机动力学参数注入仿真，缩小 gap | 见 [[系统辨识]] |

## 四、开源训练框架（"训这些模型"的代码）

| 框架 | 维护方 | 说明 |
|------|--------|------|
| **unitree_rl_gym** | Unitree | G1/H1/H1-2 官方 RL 训练库（Isaac Gym + PPO），"野外行走"就从这跑 |
| **Humanoid-Gym** | RobotEra | 开源人形 RL + zero-shot sim2real，支持 H1 |
| **legged_gym / Isaac Lab** | NVIDIA | 底层并行仿真训练框架（所有上面方法的公共地基） |

## 五、边界：哪些"人形大模型"不属于这里

| 工作 | 属于 | 原因 |
|------|------|------|
| **GR00T N1** | 08 VLA | 双系统 VLA：System 2 语言推理 + System 1 动作，管"理解+决策" |
| **π0 / π0.5** | 08 VLA | 通用 VLA 基础模型，动作生成走 Flow Matching |
| **HOVER / ExBody / ASAP** | 09 本模块 | 低层全身控制（RL），管"执行" |

**关系**：分层架构里 GR00T 是高层（给目标/意图），HOVER/WBC 是低层（把意图变成关节力矩）——两者是**上下级**，不是同类（见 [[全身协同的VLA集成]]）。

## 六、怎么读这些论文（对号入座）

```
1. 看训练源：纯仿真？动捕？影子？→ 判断"数据从哪来"
2. 看控制模式：根速度 / 参考姿态 / 全身影子 → 判断"高层怎么指挥"
3. 看 sim-to-real：域随机化 / delta model / 蒸馏 → 判断"怎么迁到真机"
4. 看硬件：G1 / H1 → 判断复现成本
```
