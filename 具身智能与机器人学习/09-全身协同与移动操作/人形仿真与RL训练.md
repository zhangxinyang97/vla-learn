# 人形仿真与 RL 训练

> **定位**：人形端到端栈 **L3/L4 的实操**。真机训练摔一次就坏一个电机，所以人形的策略几乎都在仿真里用 RL 练。本篇把"在 Isaac 里训一个人形走路/操作"这件事拆成可操作的教学步骤。
>

## 一、为什么仿真 RL 是人形的主训练场

| 对比 | 真机训练 | 仿真 RL |
|------|---------|---------|
| 成本 | 摔一次 = 换硬件 | 摔一万次 = 0 成本 |
| 并行 | 一次只能练一台 | GPU 上**上万环境并行**（Isaac Gym/Lab） |
| 数据 | 慢、贵 | 快、可无限随机化 |
| 代价 | — | **sim-to-real gap**（仿真≠现实） |

**核心矛盾**：仿真够快够安全，但和真机有 gap——所以人形 RL 的全部工程都在"训得快"与"迁移得过去"之间平衡。

## 二、引擎选型

| 引擎 | 特点 | 适合 |
|------|------|------|
| **Isaac Gym / Lab** | GPU 并行上万环境，PPO 标配，生态最好 | 人形 RL 首选 |
| **MuJoCo** | 接触力学精准、轻量 | 学术基准、单环境研究 |
| **Isaac Sim** | 照片级渲染、传感器仿真 | sim-to-real 视觉、数字孪生 |

> 人形 RL 实际工作流：Isaac Lab 训练（并行快）→ Isaac Sim 精调/视觉仿真 → 真机迁移。

## 三、一个 locomotion RL 任务怎么搭（教学拆解）

### 3.1 环境组成

```
环境（Env）= 机器人模型（URDF/MJCF）
          + 物理引擎（动力学积分，见 [[机器人动力学基础]]）
          + 地形/物体
          + 奖励函数 + 终止条件 + domain randomization
```

### 3.2 观察空间设计（关键！必须真机可测）

| 观测 | 是否真机可测 | 说明 |
|------|-------------|------|
| 关节角/角速度 | ✅ 编码器 | 基本输入 |
| 重力方向投影 | ✅ IMU | 让策略知道"哪是下"（见 [[状态估计与传感器]]） |
| 命令速度/目标 | ✅ 用户指令 | 告诉机器人往哪走 |
| 上一动作 | ✅ 内部 | 时序平滑 |
| **质心位置/速度** | ⚠️ 需要估计 | 慎用，仿真"免费"但真机难测 → 迁移后崩 |
| **接触力真值** | ❌ 难测 | 仿真里常见但真机没有 → sim-to-real 坑 |

> **隐藏大坑**：仿真里 state 全部"白送"，很多人把质心、速度等真机测不到的量塞进观测，结果仿真满分、真机崩。**观测必须只用真机能拿到的量**。

### 3.3 动作空间

| 动作 | 说明 |
|------|------|
| 关节目标位置 | 交给低层 PD 跟踪（最常见、稳定） |
| 关节力矩 | 直接输出（更灵活、训练难） |

### 3.4 奖励与终止

奖励项、终止条件、随机化——完整配方见 [[足式运动与步态]] 第四节。

## 四、训练流程（从 0 到跑通）

```
1. 装 Isaac Lab + 拉一个 humanoid 例程（Unitree G1/H1 有现成）
2. 跑通训练脚本，看懂日志：episode reward 曲线、episode 长度
3. 改 reward 权重 → 观察行为变化（调参直觉）
4. 加 domain randomization（质量/摩擦/地形/扰动）
5. 导出 policy → 部署到仿真测试场景 → （有硬件）sim-to-real
```

**看 reward 曲线的经验**：episode 长度上升 = 存活更久；速度跟踪误差下降 = 走得更稳；reward 不涨但 episode 变长 = 可能在"苟活"（不完成任务但也不摔），要查 reward hacking。

## 五、domain randomization：sim-to-real 的命脉

训练时随机化仿真参数，逼策略学会"对变化鲁棒"：

| 随机化项 | 范围 | 目的 |
|---------|------|------|
| 质量/惯量 | ±10-20% | 负载变化 |
| 地面摩擦 | 0.3-1.2 | 不同地面 |
| 地形起伏 | 台阶/斜坡/粗糙 | 复杂地形 |
| 外力扰动 | 随机推一把 | 抗扰动 |
| 观测噪声 | 加高斯噪声 | 传感器真实噪声 |
| 控制延迟 | 1-3 步延迟 | 通信/计算延迟 |

更多见 [[NVIDIA-Sim-to-Real技术]]。

## 六、常见坑速查

| 坑 | 表现 | 对策 |
|----|------|------|
| reward hacking | 用怪姿势得分不做事 | 加惩罚、抽查、调权重 |
| 观测不可测 | 仿真好真机崩 | 只留真机可测观测 |
| 欠随机化 | 换地面就摔 | 加大 domain rand 范围 |
| 动作太抖 | 关节高频振荡 | 平滑项 + 低层 PD 调参 |
| 训练不收敛 | reward 长期不涨 | 检查 reward 符号/尺度、lr、是否卡在局部 |
