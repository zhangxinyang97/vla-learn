# 人形机器人全身控制-WBC与MPC

一句话：Whole-Body Control 是同时协调腿、臂、躯干与平衡的控制框架，让人形在浮动基座下全身一起发力，而不是把每根关节当独立 PID 去调。

直觉类比：站在滑板上搬箱子。箱子很重，手一伸身体就晃，你必须在伸手的同时移动重心、微调两脚踩稳。全身控制就是这个"边保持平衡边干活"的过程。

## 为什么：浮动基座

固定底座机械臂简单，因为基座被焊死在地面，问题退化成"末端位姿 vs 世界坐标系"。人形完全不同：

- **浮动基座（floating base）**：骨盆与地面之间没有任何固定约束，躯干本身有 6 个自由度的自由运动，得靠腿的接触力"撑住"自己。
- **同时处理三件事**：质心动力学（重心落在哪）、接触力约束（脚别滑、脚别离地）、平衡稳定。三者耦合，比固定底座难一个量级。
- **高度冗余**：双腿 + 双臂 + 躯干往往 30+ 自由度，同一个末端动作有无数种"用哪根腿发力"的解，需要整体求解而不是逐关节调参。

## 怎么工作

### 质心动力学（centroidal dynamics）

把全身质量"聚"到质心，用简化方程描述平衡约束：

$$M\ddot{\mathbf{c}} = \sum_i \mathbf{f}_i + M\mathbf{g}$$

质心的平移加速度由所有接触力合力决定，旋转部分用角动量刻画。把 30+ 自由度压缩成 6 维质心运动，维数骤降却抓住了平衡的本质，是 WBC/MPC 的公共地基。

### WBC = 层级 QP 优化

把任务按优先级排进 QP 求解器，高优先级硬约束优先满足：

| 优先级 | 任务 |
|---|---|
| 1 | 质心轨迹 + 平衡（不可违反） |
| 2 | 支撑脚不动、不滑（接触约束） |
| 3 | 足端落点轨迹 |
| 4 | 双手末端位姿、躯干朝向（软任务） |

在接触约束与关节力矩上限下，求解最小二乘意义的关节加速度与力矩：$\min \| \mathbf{A}\mathbf{a} - \mathbf{b} \|^2 \quad \text{s.t. 接触、力矩约束}$。优先级低的任务只在剩余自由度里尽量做。

相比"单臂 IK + 关节 PID"的老路线，WBC 的差别在于：它把整条动力学方程 $M\ddot{\mathbf{q}} + \mathbf{C} + \mathbf{g} = \boldsymbol{\tau} + \mathbf{J}^T\mathbf{f}$ 写进同一个优化里，手臂发力会反作用于质心，所以伸出双臂时髋膝会自动补偿，而不是靠逐关节 PID 硬扛。

### MPC

模型预测控制负责"眼光放远"：滚动时域内预测未来 0.5~1 秒的质心轨迹和落脚点，只执行第一步，每步重新优化。它回答"下一步脚落在哪、重心往哪挪"，WBC 回答"这个目标下每个关节该怎么发力"，两者级联。

### RL 路线 vs 传统 WBC/MPC

| 维度 | 传统 WBC/MPC | RL（HOVER / ExBody） |
|---|---|---|
| 通用性 | 换任务要重调层级与权重 | 一套网络多模式复用 |
| 可解释性 | 强，QP 有明确物理约束 | 弱，黑盒策略 |
| 迁移性 | 建模准确即可移植 | 靠 domain randomization 硬扛 |
| 训练成本 | 低，纯优化无需数据 | 高，需要大规模仿真训练 |
| 泛化 | 对建模误差敏感 | 对未见扰动更鲁棒 |

## 在哪用

- **整机落地**：宇树（H1/G1）、智元（远征系列）、Figure 02 都走"高层 MPC 定步态 + 底层 WBC 发力矩"的路线。
- **开源框架**：PyPnC（Pinocchio + QP 力矩分配，适合手推）、OpenLoong（国内工业级全栈）、OCS2（ETH 的 MPC/WBC 数学标杆）。框架清单详见 [[人形机器人开源框架]]，本篇只补理论纵深。

## 怎么落地

- **QP 求解器**：OSQP / ProxQP，毫秒级求解，塞进 500~1000Hz 的实时循环。
- **接触规划**：MPC 前瞻决定"何时落脚、落脚点在哪"，脚一旦落地就进入 WBC 的不滑动硬约束。
- **ExBody 上下肢解耦**：腿用 WBC/MPC 保证稳定，手臂用 RL 学操作，减少耦合复杂度。
- **Sim2Real**：域随机化 + 实机参数辨识，把仿真调好的控制器搬到真机。
- **频率分层**：MPC 规划（10~50Hz）→ WBC 发关节力矩（500~1000Hz）→ 底层电流环 PID（1kHz+）。

完整链路：

```
感知/任务 → 高层规划 → MPC(10-50Hz)算质心轨迹+落脚点
    → WBC(500-1000Hz)层级QP解出关节力矩 τ
    → 关节电流环 → 电机 → 编码器/IMU/力传感反馈 → 闭环
```

## 学习路径

1. 先啃 [[正逆运动学与PID控制]]，把浮动基座和接触约束的意识建立起来。
2. 理论：质心动力学 → 单层 QP → 层级 WBC → 级联 MPC，理解每一层回答什么问题。
3. 动手：PyPnC 手写一次力矩分配，再跑 OpenLoong/OCS2 感受工业级完整度。
4. 对照 RL：用 [[人形机器人开源框架]] 里的 HOVER/ExBody 对比同样步态在 RL 下的表现。
