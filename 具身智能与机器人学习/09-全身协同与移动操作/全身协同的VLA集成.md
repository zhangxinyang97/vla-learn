# 全身协同的 VLA 集成：VLA 高层规划 + WBC 低层执行

> **是什么**：VLA 负责「高层规划 + 动作生成」，全身控制器（WBC/MPC）负责「低层执行」，两者分层集成，是当前全身 VLA 的主流架构。

直觉类比：像开车。VLA 是驾驶员，决定去哪、何时打方向盘；WBC/MPC 是底盘与转向系统，把「想去的方向」翻译成每个瞬间的轮子转角与扭矩。司机不关心轮胎动力学，底盘不管目的地，各司其职。

## 为什么分层，而不是端到端

- **数据劝退**：端到端全身 VLA 需要整身动作 + 力矩标注，双腿 + 躯干 + 双臂同时采集极难，短期劝退
- **泛化难**：高维动作空间（20-40+ 自由度）+ 强平衡约束，直接学全身力矩，端到端模型难泛化、难保安全
- **分层解耦**：把「想做什么」（语义/高层动作）与「怎么全身发力」（运动学/动力学执行）分离，各用最优方案，不是妥协而是扬长避短

## 怎么工作：三层流水线

```
VLM（理解指令）→ 技能/规划器（选技能）→ WBC/MPC（全身执行）
```

- 上层 VLM 输出语言级意图，技能库/规划器将其映射为具体技能与动作目标
- 低层 WBC/MPC 接收末端/质心参考，在线求解全身力矩，兼顾平衡、接触力与关节限位

## 在哪用：代表工作怎么集成

### GR-2（字节）
AR + CVAE 生成动作，低层用 **WBC 兜底**：策略只管出动作序列，WBC 负责稳定执行，弥补生成式动作在物理稳定上的短板。

### GO-1 / ViLLA（智元）
VLM + MoE 的 ViLLA 架构：
- **Latent Planner（隐式规划器）**：跨本体 + 人类操作视频 → 通用动作理解
- **Action Expert（动作专家）**：百万真机数据 → 精细动作执行
- 预测 **Latent Action Tokens**，输出上层动作意图，交低层落地为真机控制

### HumanPlus（Stanford）
VLM 高层 + 模仿学习技能库：HIT 高层技能策略选技能，HST 低级策略做全身「影随」执行，天然是 VLM 选技能、低层学执行的分层结构。

## 对比：端到端全身 VLA vs 分层 VLA+WBC

| 维度 | 端到端全身 VLA | 分层 VLA+WBC |
|------|--------------|--------------|
| 数据需求 | 整身动作+力矩标注，极难采集 | 高层只要动作标签，低层复用传统控制 |
| 泛化 | 跨本体弱，数据不足易过拟合 | 高层语义泛化 + 低层物理通用 |
| 安全 | 缺乏硬约束，易越界/失衡 | WBC 硬约束兜底，平衡与限位有保证 |

## 怎么落地

- **技能库 + 状态机**：VLM 选技能，状态机驱动技能切换，低层控制器按技能执行
- **WBC 作为安全兜底**：无论上层策略如何生成动作，WBC 始终保证全身稳定与安全
- **VLA 输出作 WBC 参考轨迹**：VLA 出末端/质心参考，WBC 转全身力矩，兼顾学习泛化与物理可行
